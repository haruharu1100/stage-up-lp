# 指標の定義（ここを唯一の基準にする）

数字の話をする時は、必ずこの定義に従う。定義を変えたい時は、先にこのファイルを直してから測る。

## 1. 集客（流入）
- **対象＝GA4「セッションのデフォルト チャネル グループ」の Organic Search ＋ AI Assistant の合計。内訳も必ず併記する。**
- AI Overviews / AI Mode からの訪問は **AI Assistant ではなく Organic Search に入る**。二重に数えない。
- AI Assistant チャネルは 2026-05-13 に追加された。**それより前の期間は遡って分類し直されない**ので、
  前年同期比で「AI流入が急増」と書かない。
- リファラの無い流入（アプリ内ブラウザ・コピペ）は Direct のまま。**AI流入は実際より少なく出る**前提で読む。

## 2. 露出
- Search Console の表示回数。**生成AIパフォーマンスレポートの数字は、通常のウェブ検索レポートにも含まれる**。
  足して「総露出」にしない。生成AIレポートにクリック数と検索語は無い。
- Search Console のクリック数と GA4 のセッション数は**定義が違うので一致しない**。片方を誤りと決めつけない。
- Search Console API は全行の返却を保証していない。**取得できた範囲**を必ず記録する。

## 3. 問い合わせ（ここを事業の成果とする）
段階を分けて数える。まとめて「リード数」と呼ばない。
1. **CTAクリック** … リード獲得ではない
2. **フォーム送信完了** … 送信イベントが実際に発火したもの
3. **資料到達・自動返信の到達**
4. **有効な相談** … 対象顧客・相談内容・対応地域の条件を満たすもの（採用応募・営業メールは除外）

- 同じ人の複数回の申込みを、何人分にも数えない。資料請求と相談は別件で管理する。
- 外部ページ（X等）の成果は、自社で計測できない限り「不明」と書く。

## 4. 目標の立て方
- 「集客3倍」は **流入3倍** のこと。流入1.5倍 × 問い合わせ率2倍 ＝ 問い合わせ3倍であって、集客3倍ではない。
- 目標はページ群ごとに積み上げ、**重複しない**ようにする。積み上げて届かないなら、
  対象市場・期間・狙う需要を見直す。**足りない数字を作文で埋めない。**

## 5. 「増えた理由」の扱い
- 公開後に数字が動いたら、まず**施策以外の説明**（季節性・広告・SNS・セミナー・計測変更・欠損）を確認する。
- 可能なら、条件の近い**未改修ページ**と比べる。
- 十分なデータが無ければ、成功とも失敗とも決めず「判断保留」と書き、次に必要な観測を決める。
