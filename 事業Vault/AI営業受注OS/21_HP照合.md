# ホームページが本当にその会社のものか

> このシステムで一番大きい事故は「別の会社のHPを読んだまま、その会社宛ての営業文を書く」ことです。
>
> 最終更新: 2026-08-31 ／ 自動生成（`npm run obsidian:sync`）。手で書き足した内容は次回の実行で消えます。

## ★恒久ルール

> **社名が一致しただけでは、そのHPをその会社のものとして採用しない。**

日本には同じ社名の別会社が数多くあります（「株式会社さくら建設」は全国にあります）。
社名の一致だけで採用すると、隣の県の同名会社のHPを読み、その内容で営業文を書きます。
受け取った側から見れば「調べもせずに送ってきた営業」と同じで、取り返しがつきません。

## 採用してよい条件（このどれか）

1. ページの中にその会社の**法人番号（13桁）**が書いてある → それだけで確定
2. **社名以外の決め手（法人番号・電話番号・所在地・代表者名）が最低1つ**一致し、
   材料が**2種類以上**、合計点が**60点以上**
3. 国が法人番号にひも付けて公開しているHP（**gBizINFO**）である

これ以外はすべて **UNKNOWN**。HPとして採用せず、空欄のまま残します。

## 法人番号の照合（鍵は要らない）

国税庁が誰でもダウンロードできる形で配っている**全件データ**と突き合わせます。APIキーは不要です。
（`npm run companies:corpnum`。鍵は、あとから差分を速く更新するための補助にすぎません。）

| 状態 | 会社数 |
|---|---|
| 照合済み（国のデータで1件に絞れた） | 193 |
| 国のデータに無い | 57 |

### 決め方（この順に見る）

1. すでに番号が入っている → 国のデータの商号と照らす。
   一致すれば**照合済み**。食い違えば**別会社の疑い**とし、その場で営業対象から外す（BLOCK）。
2. 商号が国のデータに1件も無い → **国のデータに無い**。似た会社を当てはめない。
3. 商号は見つかったが住所が合わない → **国のデータに無い**扱い。
4. 住所まで合う候補が**2件以上** → **絞れない**。★ここで1件も選びません。
5. 住所まで合う候補が**ちょうど1件** → **照合済み**。

> **候補が2件以上あるときに1つ選ぶと、別の会社へ営業をかけることになります。だから選びません。**
> 未照合は未照合のまま画面に出します。空欄にすると「見落とし」と「取れなかった」の区別が付かなくなるため、
> 必ず理由の文を添えます。

### 文字コードの落とし穴（実際に起きた）

国が配るCSVは Shift_JIS です。これをそのまま UTF-8 として読むと商号が全部文字化けし、
**登録済みの130社すべてが「別会社の疑い」**という誤った結論になりました。
いまは必ず変換してから読みます。この一件があるので、照合は必ず `--dry`（書き込まない）で
結果を見てから本番に流します。

## 不採用にする条件（点数がいくら高くても）

- ページに**別の法人番号**が書かれている
- 社名が見つからず、代わりに**別の法人格つき社名**が載っている
- 求人サイト・プレスリリース・SNS・地図など、**その会社が書いた文章ではない場所**
- 別ドメインへ転送された

## 点数の付け方

| 一致した材料 | 点 | 備考 |
|---|---|---|
| 法人番号 | 100 | これだけで確定 |
| 会社名（本文） | 50（短い社名は35） | これだけでは採用しない |
| ページの題名で名乗っている | 45 | サイトの持ち主の自己申告なので、本文中の言及より強い |
| 電話番号 | 40 | 決め手として数える |
| 所在地（そのまま） | 40 | 決め手として数える |
| 所在地（市区町村まで） | 25 | 決め手として数える |
| 代表者名 | 25 | 決め手として数える |

合格ライン: **60点以上 かつ 2種類以上 かつ 決め手が1つ以上**

## 事故を止めるための後始末

照合に落ちたとき、HPのURLを消すだけでは足りません。
その会社のものとして保存した**問い合わせフォームのURL**と**メールアドレス**が
同じドメインなら、それらも一緒に消します。
HPだけ外してフォームを残すと、結局その別会社へ送ることになるためです。

## 文面への影響（ここが本題）

- 照合済みのHPがある会社にだけ「**公式サイトを拝見しました**」と書きます。
- 未照合の会社には「**公開されている情報を拝見し**」としか書きません。
- この差はテストで機械的に確認しています（未照合の会社の文面に「公式サイトを拝見」が出たら不合格）。

## 相手のサーバへの配慮

- robots.txt を読み、**読めなかったときは読まない**（許可と解釈しない）
- 1社あたり最大3ページ（トップ・会社概要・お問い合わせ）
- 同じ相手への連続アクセスは既定1500ミリ秒空ける（Crawl-delay の指定があればそちらを優先）
- メニューが機械で読めないHPのときだけ、そのサイト自身が公開している sitemap.xml を見る
- 読むだけ。フォーム送信・ログイン・投稿は一切しない
