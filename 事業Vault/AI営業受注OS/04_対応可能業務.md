# 対応できる作業の種類

> 案件文からこの種類を拾い、上の道具と突き合わせます。
>
> 最終更新: 2026-08-31 ／ 自動生成（`npm run obsidian:sync`）。手で書き足した内容は次回の実行で消えます。

| 作業の種類 | 内容 |
|---|---|
| 調査・情報収集 | リサーチ／市場調査／競合調査／営業リスト |
| 文章作成 | 記事／コピー／キャッチ／商品説明文／台本／シナリオ |
| 画像・デザイン | バナー／サムネイル／画像生成／イラスト |
| 構築・実装 | サイト制作／LP制作／WordPress／GAS／スプレッドシート／システム開発 |
| 運用・投稿 | SNS運用／投稿代行／更新／管理代行 |
| 分析・集計 | データ分析／集計／レポート作成 |

## 積極的に受ける

キャッチコピー／SNS投稿・X投稿／ブログ・SEO記事／商品説明／LP／営業文章／画像生成／AI導入支援／GAS／Webシステム／WordPress／EC・Amazon支援／データ分析／営業リスト作成／市場調査／動画台本

## 受けない（自動で除外）

| 除外の理由 | なぜ受けないか |
|---|---|
| 1日8時間などの長時間拘束 | 時間を売る仕事はAIで置き換えられず、他の案件が全部止まる |
| 週5日などの固定シフト | 曜日が固定されると他の仕事を入れられない |
| 正社員・アルバイト等の雇用 | 業務委託ではないので受けられない |
| 常駐・出社が必要 | 場所を拘束されるとAIで自動化できない |
| 時給での労働が中心 | 成果ではなく時間で払われる仕事は、AIを使うほど自分の取り分が減る |
| 常時対応・即レス要求 | 待機そのものが拘束になる |
| 週20時間以上の拘束 | 週の時間を先に押さえられると、AIで短縮しても自分の取り分が増えず、他の案件を入れる余地も消える |
| 毎日の定例参加が必須 | 毎日決まった時刻に呼ばれると、その時間は他の案件に使えない |
| 日中の常時連絡が必須 | 日中いつでも応じる約束は、待機時間ごと売っているのと同じ |
| 作業時間を計測・監視される | 時間を測られる契約は成果ではなく時間を売る契約。AIで速く終わらせるほど損をする |
| PC画面を監視される | 画面を撮られる働き方はAIでの自動化と両立しない（自動化そのものが問題視される） |
| 違法・犯罪に関わる | 受けてはいけない |
| 本人確認の偽装・なりすまし | アカウント停止と法的責任に直結する |
| 第三者アカウントの操作 | 各サービスの規約違反になる |
| 規約違反を求めている | 依頼どおりに作ると規約違反になる |
| サクラ・やらせ | 景表法（ステマ規制）違反になる |
| AI利用が禁止されている | AIを使えない仕事は、自分がやる意味がない（時間だけ消える） |
| アダルト・出会い系 | 入金手段と法令の面で扱えない |
