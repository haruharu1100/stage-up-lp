# 権限ルール（AIが勝手にやっていいこと／人間承認が必要なこと）

親: [[00_仕様書_最上位]]

> [!danger] 判断に迷ったら「承認が必要」側に倒す
> お金が出ていく・外に公開される・取り消しにくい、のいずれかに当てはまるものは**必ず人間の承認**。

---

## ✅ AIが自動でやってよいこと

| 内容 | 条件 |
|---|---|
| 商品の発掘・解析・A/B/C/Dランク分類 | 常時 |
| 価格・ランキング・競合・レビューの分析 | 常時 |
| 利益計算・BREAK_EVEN_ACOS・TARGET_ACOSの算出 | 常時 |
| 商品タイトル・SEOキーワード・説明文の**下書き**作成 | 公開はしない |
| 商品ページ画像の生成 | **MASTER画像が登録済みの場合のみ** |
| 動画の**企画**作成 | 常時 |
| コンプライアンス（規約・食品表示・商標）チェック | 常時 |
| **広告入札の ±10% 以内の調整** | サンプル数が十分にある場合のみ |
| 無駄キーワードの除外候補の**抽出** | 抽出まで（停止実行は下記参照） |
| 週次の広告監査・状態分類・レポート生成 | 常時 |
| 商品ハンターの通知 | 常時 |
| 実績DBへの記録と採点の重み再計算 | 実績5件以上・変更幅±20%以内 |

---

## 🛑 人間の承認が必要なこと

| 内容 | 理由 |
|---|---|
| **仕入れ発注** | 現金が出る。数量判断もAIは提案まで |
| **新規商品のAmazon公開（出品）** | 取り消しが効きにくい・規約リスク |
| **広告予算の大幅増額** | 現金が出る |
| **広告入札の ±10% を超える変更** | 影響が大きい |
| **キーワードの停止・除外の実行** | 販売機会を失う可能性 |
| 販売価格の変更 | 利益とランキングに直結 |
| MASTER画像の登録（権利区分の申告） | 権利の責任は人間が持つ |
| `AMAZON_AUTO_PUBLISH` を true にする | 本番送信の解禁 |
| `AD_AUTO_OPTIMIZE` を true にする | 広告自動変更の解禁 |
| 新しい外部APIの契約・課金 | 費用が発生 |

---

## 🚫 AIが絶対にやってはいけないこと

- Amazonサイトの無許可スクレイピング
- Amazonや他社の商品画像のコピー・流用
- MASTER画像が無いのに商品画像を作ること（サンプル・mockでも禁止）
- 商品の形・色・容量・内容量・パッケージ表記を勝手に変えること
- 誇大表示・虚偽表示、存在しない効果効能の生成（特に食品の健康効果・疾病改善）
- APIキーをコードに直接書くこと
- コンプラAIが「停止」を出しているのに出品を進めること

---

## 停止装置（フェイルセーフ）

- コンプライアンスチェックで **1つでも「停止」が出たら AUTO PUBLISH を止める**
- 広告後純利益が継続マイナス → 広告を強制的に弱める
- 在庫が欠品リスク → 広告を停止または大幅削減
- 実績データが5件未満 → 学習による重み変更を行わない
