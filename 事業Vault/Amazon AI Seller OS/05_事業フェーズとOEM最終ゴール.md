# 事業フェーズとOEM最終ゴール

親: [[00_仕様書_最上位]]

> [!important] 最終ゴール
> **自社OEM商品を作り、自社ブランドとして売ること。**
> このOSは転売ツールではない。**OEMを当てるための市場検証エンジン**である。
> 転売フェーズは「現金リスクゼロで売れる商品を特定するための調査工程」と位置づける。

---

## 🚫 やってはいけない仕入れ方（2026-08-19 確認・却下した案）

### ① Amazon内のライバル出品者から買って、お客様へ直送する
**Amazonのドロップシッピングポリシー違反。** 「他の小売業者から購入し、その業者に直接顧客へ発送させること」は明確に禁止されており、アカウント停止事由。
他社の納品書・請求書・外装が同梱された状態での発送も禁止。
実利面でも、ライバルの利益＋Amazon手数料を二重に払うため利益が残らない。

**→ 正しい形**：仕入れ先は必ず **Amazonの外**（卸・メーカー・eBay・Alibaba・国内問屋）。
商品は一度**自分の手元に届け、自分で検品・梱包し、自分の名前の納品書で発送**する。
これは「受注してから仕入れる普通の店」であり完全に合法・規約内。

### ② 既にAmazonにある商品で、自分の新規ページを作る
**重複出品違反。** 統合・削除される。既存商品は既存ASINに相乗りする。

### ③ ライバルの1枚目画像をAIで作り直して使う
**却下。** 作り直しても翻案として著作権侵害になり得る。商品パッケージ自体にメーカーの著作権・商標がある。加えて実物と細部が必ずズレるためAmazon規約違反＋景表法（優良誤認）。
**→ 正しい形**：実物を1個だけ先に仕入れて**自分で撮影**する。自分で撮った写真なら、背景合成・訴求文字・シーン画像などAIで自由に展開できる（**ただし商品の形・色・容量表記は変更しない**）。

---

## 新規ページを作ってよい条件

| 状況 | 新規ASID作成 | 対応 |
|---|---|---|
| その商品がAmazonにまだ無い（eBay等にはある） | ⭕ **本命** | 新規ページを作る。1個先に仕入れて実物撮影 |
| その商品がAmazonに既にある | ❌ | 既存ASINに相乗り |
| 自社OEM商品 | ⭕ | ブランド登録して新規ページ（フェーズ3） |

## フェーズ1：無在庫・自己発送で「売れる商品」を特定する

**目的は利益ではなく、現金リスクをかけずに「本当に売れるか」の実データを取ること。**

1. **Amazonにまだ無い商品**をeBay・海外サイト・卸から発掘する（Keepa＋Web調査AI）
2. 新規ページを作成し、**自己発送**で出品（出荷作業日数を実際のリードタイムに合わせて長めに設定）
3. 注文が入ったら仕入れる → **自分の手元に届く** → 検品・梱包 → 自分の名前で発送
4. 何が売れたか・何個・どの価格で売れたかを全部DBに記録する

**守る数値（アカウント健全性）**：出荷遅延率 4%未満 ／ 注文不良率 1%未満 ／ 出荷前キャンセル率 2.5%未満
→ 納期設定は必ず余裕を持たせる。AIはこの3指標を監視し、危険水域で新規出品を止める。

## フェーズ2：売れた商品をまとめ仕入れ＋FBA

フェーズ1で**実際に売れた商品だけ**、eBay・Alibaba・国内卸からまとめて仕入れFBA化する。

- **FBA切替判断AI**：「何個売れたらFBAに切り替えるか」を判定する
  （判断材料：週間販売数の安定性／粗利／仕入ロット単価／保管手数料／資金）
- ここで初めて利益が出るフェーズ。広告最適化AI（[[01_広告最適化AI仕様]]）が本格稼働する

## フェーズ3：OEM（最終ゴール）

売れることが確定したカテゴリで、自社ブランド版を作る。

### OEMの設計図＝レビュー分析AIの蓄積

> [!tip] このOSの最大の価値
> フェーズ1〜2の間、**レビュー分析AIがライバル商品の低評価レビューを集め続ける**。
> これが「そのカテゴリのお客さんが本当に困っていること」のデータベースになる。
> 不満（例：フタが開けにくい／サイズが想定より小さい／においが残る）を潰した商品を設計すれば、
> それは**勝つことが分かっている商品**。
> ゼロからOEMを企画するのが最も失敗する。**この順番なら失敗しない。**

→ レビュー分析の結果を **「OEM改善要件」** として商品カテゴリ単位で蓄積するテーブルを持つ。

### 先に動かすべきこと：商標登録

Amazonブランド登録には**登録商標**が必要。日本の商標は取得まで**半年〜1年**かかる。
**フェーズ3で慌てると1年待ちになるため、ブランド名を早期に決めて出願しておく。**
→ これは人間（ユーザー）のタスク。AIは代行できない。

## 輸入規制チェック（コンプラAIに追加）

海外仕入れは、商品によって輸入自体に許可・表示が必要。**仕入れ判断の前に必ず判定する。**

| 商品 | 規制 |
|---|---|
| 食品・食器・乳幼児用玩具 | 食品衛生法（輸入届出） |
| 化粧品・サプリ・医薬部外品 | 薬機法 |
| 充電器・電源を使う家電 | PSEマーク |
| Bluetooth／Wi-Fi機器 | 技適マーク |
| ブランド品 | 商標（並行輸入の要件） |

判定は「販売可 / 要確認 / 販売不可」の3段階。**「要確認」以上は仕入れ承認画面に赤字で出す。**
