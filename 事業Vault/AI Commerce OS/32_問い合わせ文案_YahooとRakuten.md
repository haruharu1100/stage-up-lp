## なぜ問い合わせるのか（1行で）

**「使ってよいか、公式に書いていない」から。**
書いていないことを「たぶん大丈夫」と解釈して接続するのが、この事業で一番やってはいけないことです（ルール58・145）。
だから、勝手に判断せず、運営元に直接聞いて、返事を証拠として残します。

## 2. 楽天ウェブサービス への問い合わせ文（そのままコピーして使える）

### なぜ楽天を「すぐ実装」しないのか

楽天ウェブサービスの規約には、次の2点の制限があると指摘されています。

1. 楽天アフィリエイト以外の方法で収益を得ること
2. 特定の人しかアクセスできない環境でウェブサービスを利用すること

AI Commerce OS は **社内限定の仕入判断システム**で、**アフィリエイト送客もしません**。
つまり、上の2点に**両方あたる可能性がある**利用形態です。
そのため「禁止」と決めつけるのではなく、**明示の許可が取れるかを確認する**という扱いにしています。

> [!warning] 原文の再確認は必ず人間が行う
> 上の2点は指摘内容であり、**AIが最新の規約原文をこの文書に転記することはしません**。
> 送信前に、人間が楽天ウェブサービスの規約ページを開いて、
> 現在の条項番号と原文を確認してから送ってください（条項は改定されます）。

### 件名

```
楽天ウェブサービスの利用可否について（社内の仕入判断での利用に関する個別許諾のご相談）
```

### 本文


## 4. バリューコマースへの問い合わせ文（最終版・このまま送れます）

> [!danger] 役割は「仕入先」ではありません
> バリューコマースの位置づけは **PRICE DISCOVERY / MARKET INTELLIGENCE（安い店舗を見つける装置）** です。
> `SOURCE_TYPE = AFFILIATE_DATA / MARKET_INTELLIGENCE`、`PURCHASABLE_SUPPLIER = UNKNOWN`。
> **許可が出ても、当社の仕入先にはなりません。** この前提でこの文面を送ります。

> [!note] この文案は「そのまま送れる最終版」です
> 直すのは末尾の署名欄だけです。本文は編集不要です。

### なぜ聞くのか

商品APIは価格・在庫・**JANコード**・型番・商品URL・画像がすべて揃う、日本で唯一の無料候補です。
ただしアフィリエイト利用規約 第4条2項13号に「主要なコンテンツの表示にログインが必要な場合」が
**登録拒否事由**として挙げられており、社内限定の非公開画面で使えるかが分かりません。

### 件名

```
商品APIの利用可否について（アフィリエイト掲載を伴わない社内利用）
```

### 本文

```
バリューコマース株式会社 ご担当者様

お世話になっております。
商品APIの利用を検討している事業者です。

アフィリエイト利用規約および商品APIリファレンスを拝読しましたが、
当方の利用形態について判断できない点がございましたので、お伺いいたします。

【当方の利用形態】
・法人（個人事業）が、自社の仕入判断のために社内で利用します。
・商品APIで取得した価格・在庫・JANコード・型番・商品URLを、
  社内の担当者のみが閲覧する管理画面に表示します。
・一般公開のWebサイトやアプリは作らず、広告リンクの掲載も行いません。
  したがって成果（送客・売上）は発生しません。
・取得した情報を第三者へ販売・再配布することはありません。

【お伺いしたい点】

1. 法人が、自社内部の仕入判断および価格比較分析のために
   商品APIを利用することは可能でしょうか。

2. 商品APIで取得したデータを、自社のデータベースに保存することは
   可能でしょうか。保存期間の上限や削除条件があればご教示ください。

3. 取得した価格情報を、Amazon等の他市場のデータと比較して
   分析することは可能でしょうか。
   （比較結果を外部に公開する予定はなく、社内の仕入判断にのみ用います）

4. 一般公開せず、社内の担当者のみが閲覧する非公開の管理画面で
   利用することは可能でしょうか。
   規約第4条2項13号に「主要なコンテンツの表示にログインが必要な場合」が
   登録拒否事由として挙げられているため、確認させていただきたく存じます。
   あわせて、広告を表示しない場合のadタグ（表示数カウント用）の
   取り扱いについてもご教示ください。

5. 商品APIで取得した商品リンクから、当方が事業目的で実際に商品を
   購入することについて、制約はございますでしょうか。
   （当方は「アフィリエイト送客」ではなく「自社が仕入れる」目的で
   商品情報を参照することを想定しております）

6. 本利用形態が認められない場合、その旨をご教示ください。
   その場合、当方はAPIの利用を行いません。

現時点では、APIへの接続は一切行っておりません。
お手数をおかけいたしますが、ご回答いただけますと幸いです。

何卒よろしくお願い申し上げます。

────────────────
（氏名 / 屋号）
（メールアドレス）
（電話番号）
────────────────
```

### 返事が来たときの扱い

> [!danger] 許可が出ても、バリューコマースは「仕入先」にはならない
> 商品APIは **アフィリエイトサイト向けの商品API** として提供されているものです。
> **「APIに商品URLがある＝当社がそこから仕入れられる」とは扱いません。**
> 社内利用が正式に許可された場合でも、役割は **PRICE DISCOVERY CONNECTOR（安い店舗を見つける装置）** であり、
> `PURCHASABLE_SUPPLIER` は **UNKNOWN のまま**です。
> 「その店舗から事業として仕入れてよいか」は、**店舗（広告主）ごとに別のGate**で判定します。

| 返事 | やること |
|---|---|
| 1〜5すべて可 | `MARKET_INTELLIGENCE` として正式採用。**Price Discovery Connector** の候補になる。ただし `PURCHASABLE_SUPPLIER` はUNKNOWNのまま |
| 社内利用は可・購入は店舗次第 | 想定どおり。店舗ごとのGateを設計する |
| 一部だけ可 | 可の項目だけYESにする。残りはUNKNOWNのまま |
| 不可 | `BLOCKED` 確定。理由の原文を保存 |
| 返事が来ない | **UNKNOWNのまま。接続しない（無返信を許可の根拠にしない）** |
