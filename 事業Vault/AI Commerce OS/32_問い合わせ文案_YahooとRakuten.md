## なぜ問い合わせるのか（1行で）

**「使ってよいか、公式に書いていない」から。**
書いていないことを「たぶん大丈夫」と解釈して接続するのが、この事業で一番やってはいけないことです（ルール58・145）。
だから、勝手に判断せず、運営元に直接聞いて、返事を証拠として残します。

| 市場 | 状態 | 意味 |
|---|---|---|
| Yahoo!ショッピング | `BLOCKED_PENDING_CONFIRMATION` | 返事が来るまで接続しない。禁止と決めつけてもいない |
| 楽天市場 | `EXPLICIT_PERMISSION_REQUIRED` | 明示の許可が取れるまでLive Connectorにしない |

## 2. 楽天ウェブサービス への問い合わせ文（そのままコピーして使える）

### なぜ楽天を「すぐ実装」しないのか

楽天ウェブサービスの規約には、次の2点の制限があると指摘されています。

1. 楽天アフィリエイト以外の方法で収益を得ること
2. 特定の人しかアクセスできない環境でウェブサービスを利用すること

AI Commerce OS は **社内限定の仕入判断システム**で、**アフィリエイト送客もしません**。
つまり、上の2点に**両方あたる可能性がある**利用形態です。
そのため「禁止」と決めつけるのではなく、**明示の許可が取れるかを確認する**という扱いにしています。

> [!warning] 原文の再確認は必ず人間が行う
> 上の2点は指摘内容であり、**AIが最新の規約原文をこの文書に転記することはしません**。
> 送信前に、人間が楽天ウェブサービスの規約ページを開いて、
> 現在の条項番号と原文を確認してから送ってください（条項は改定されます）。

### 件名

```
楽天ウェブサービスの利用可否について（社内の仕入判断での利用に関する個別許諾のご相談）
```

### 本文

```
楽天ウェブサービス ご担当者様

お世話になっております。
楽天ウェブサービス（商品検索API等）の利用を検討している事業者です。

利用規約を拝読したところ、
・楽天アフィリエイト以外の方法で収益を得る利用
・特定の方のみがアクセスできる環境での利用
について制限がある旨を確認いたしました。

当方が検討している利用形態は、この2点に該当する可能性があるため、
自己判断で接続することは避け、事前にご相談させていただきます。

【当方の利用形態】
・法人（個人事業）が、自社の仕入判断のために社内で利用します。
・社内の担当者のみがアクセスできる管理画面で、商品情報を確認します。
・楽天アフィリエイトによる送客は行いません。
・APIで取得した価格情報を、他の市場の価格と比較し、
  自社が仕入れるべき商品かどうかを判断する用途に使います。
・取得した情報を再配布・再販売することはありません。
・スクレイピングは一切行わず、公式APIのみを利用する前提です。

【お伺いしたい点】

1. 上記のような「社内限定・アフィリエイト送客なし・仕入判断目的」の利用について、
   個別に許可をいただくことは可能でしょうか。

2. 可能な場合、必要な手続き（申請書類、審査、契約、費用の有無）をご教示ください。

3. 許可の対象となる場合、取得データの自社データベースへの保存、
   および他市場価格との比較分析は認められますでしょうか。

4. 第10条(7)（別途定める目的以外での使用の禁止）および第10条(9)
   （情報の保管の禁止）については「明示的に許可した場合を除く」との
   除外規定がございません。上記1の許可をいただけた場合、
   これらの条項との関係はどのように整理されますでしょうか。

5. 第8条4項に「アプリケーション上のウェブサービスを使用した部分においては、
   楽天サイト以外のウェブサイトへのリンクを設置してはならない」とございます。
   当方の管理画面は、同じ画面内にAmazon等の商品ページへのリンクを
   並べて表示する形になります。これは同項に抵触いたしますでしょうか。

6. もし本利用形態が許可の対象外である場合は、その旨をご教示ください。
   その場合、当方は接続を行いません。

現時点では、APIへの接続は一切行っておりません。
お手数をおかけいたしますが、ご回答いただけますと幸いです。

何卒よろしくお願い申し上げます。

────────────────
（氏名 / 屋号）
（メールアドレス）
（電話番号）
────────────────
```

## 3. NETSEA（SynaBiz）への問い合わせ文 ★最優先

### 件名

```
NETSEA API利用規約 第8条2項の書面承諾について（自社内部の仕入判断での利用）

### 本文

```
株式会社SynaBiz NETSEA ご担当者様

お世話になっております。
NETSEA バイヤー会員として、Buyer APIの利用を検討している事業者です。

NETSEA API利用規約を拝読し、当方の利用形態について
確認が必要な点がございましたので、ご相談させていただきます。

【当方の利用形態】
・法人（個人事業）が、自社の仕入判断のために社内で利用します。
・APIで取得した商品情報（JANコード・卸価格・在庫有無・商品URL）を
  自社のデータベースに保存します。
・保存した卸価格を、Amazon等での想定販売価格と比較し、
  「その商品を仕入れるべきか」を社内で判断する材料に使います。
・判断結果を表示する管理画面は、社内の担当者のみが閲覧します。
  一般公開のWebサイトやアプリは作りません。
・取得したデータを第三者へ販売・再配布・再許諾することはありません。

  APIによる自動発注は行いません。

【お伺いしたい点】

1. 上記のような「取得した卸価格を他市場の相場と比較し、社内の仕入判断に使う」
   利用は、規約第8条2項の「情報を加工する」に該当しますでしょうか。
   該当する場合、書面による承諾をいただくための手続きをご教示ください。

2. 規約第2条は「本ライセンスをAPIユーザー自身の便益をはかる商用目的に
   使用することを認める」としております。
   一方、第5条3項では「本ライセンスの使用または提供から収入を得ること」を
   事前の明示的書面による許諾なく行うことを禁じております。
   当方のように「APIで得た情報をもとに仕入れた商品を販売して利益を得る」場合、

3. 取得したデータの自社データベースへの保存について、
   保存期間の上限や、削除が必要となる条件はございますでしょうか。

4. APIのリクエスト回数の上限（レート制限）について、
   具体的な数値（1秒／1分／1日あたり）をご教示ください。
   規約第5条4項の「合理的に必要相当な数を超える使用」の基準として
   参照させていただきたく存じます。あわせてAPI利用料金の有無、
   および利用申請に審査があるかどうかもご教示ください。

5. 当方が仕入れた商品をAmazon等のマーケットプレイスで販売することについて、
   プラットフォームとしての制限はございますでしょうか。
   API のレスポンスには deal_net_shop_flag（ネット販売可）がございますが、
   Amazon・楽天市場・Yahoo!ショッピング等を個別に区別する項目は
   見当たりませんでした。個々のモールでの販売可否は、
   サプライヤー様へ個別に確認する必要があるという理解でよろしいでしょうか。

6. API の direct_send_flag（商品配送可）と、CSV の「消費者直送可」欄は

## 4. バリューコマースへの問い合わせ文

### なぜ聞くのか

2. 商品APIで取得したデータを、自社のデータベースに保存することは

### 返事が来たときの扱い

> [!danger] 許可が出ても、バリューコマースは「仕入先」にはならない
> 商品APIは **アフィリエイトサイト向けの商品API** として提供されているものです。
> **「APIに商品URLがある＝当社がそこから仕入れられる」とは扱いません。**
> 社内利用が正式に許可された場合でも、役割は **PRICE DISCOVERY CONNECTOR（安い店舗を見つける装置）** であり、
> `PURCHASABLE_SUPPLIER` は **UNKNOWN のまま**です。
> 「その店舗から事業として仕入れてよいか」は、**店舗（広告主）ごとに別のGate**で判定します。

| 返事 | やること |
|---|---|
| 1〜5すべて可 | `MARKET_INTELLIGENCE` として正式採用。**Price Discovery Connector** の候補になる。ただし `PURCHASABLE_SUPPLIER` はUNKNOWNのまま |
| 社内利用は可・購入は店舗次第 | 想定どおり。店舗ごとのGateを設計する |
| 一部だけ可 | 可の項目だけYESにする。残りはUNKNOWNのまま |
