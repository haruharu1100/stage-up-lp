全41案件のうち提携済みは7件だけで、そのうち格安SIMは楽天モバイル1社。
**つまり今LPを作っても、比較表8行のうち7行は「リンクなし」になる。**
売上はほぼ楽天モバイル1本に頼ることになる。

比較表としては成立する（リンクが無くても比較情報は載せられる）が、
**収益の入口が1つしかない状態で30日回しても、数字は「楽天モバイルが
刺さるかどうか」しか分からない。** ASP提携の追加申請が、LPより先。

### 2. 「通話オプション」は、データが2社分しかない

比較軸に入れたいとのことでしたが、いま手元にあるのは
楽天モバイル（Rakuten Link で国内通話無料）と ahamo（5分以内無料）だけ。
残り6社は未収集です。

事実でないことは書けないので、選択肢は2つ：
- **(A)** 各社公式サイトで調べて、出典URLと確認日を付けて埋める
- **(B)** 初版では通話の列を作らない

★推奨は (A)。「通話が多い人」は格安SIM選びで一番迷う層なので、
ここが空欄だと比較表の価値が落ちる。ただし調べる手間はかかる。

### 3. 独自ドメインが1つも無い

通信比較ナビは `stage-up-lp.vercel.app` の中の `/a/` で動いている。
これは**法人営業LP「STAGE UP」と同じドメイン**。
他に持っているのは gorogorogacha.com と cocohoreone.jp（どちらもトレカEC）で、
節約系のあおいを載せるにはテーマが合わない。

つまり「既存の健全なドメインのサブドメイン」という選択肢が、実際には無い。

現実的な案：

| 案 | 置き場所 | 良い点 | 悪い点 |
| --- | --- | --- | --- |
| **A** | `stage-up-lp.vercel.app/aoi/` | 今日から作れる・0円 | SNSプロフィールに貼るリンクが `vercel.app` になる。個人ブランドとして信用されにくく、クリック率が落ちる |
| **B** | 独自ドメインを1つ取る（年1,000〜1,500円） | プロフィールリンクが自然。移行不要 | 1,500円かかる |

★おすすめは **A で作って、実測を始める前にBへ移す**。
理由は、案Aのままだと「クリックされなかった」のが
「LPが悪いから」なのか「vercel.app が怪しく見えたから」なのか
区別できなくなるためです。1,500円の節約のために、
30日の実測が読めなくなるのは割に合いません。

どちらでも作れる形（フォルダごと移せる作り）にはします。

## 1. LP構成

### 全体の流れ

```
SNS投稿（Instagram / X / TikTok）
   ↓  プロフィールのリンク1本 ＋ ストーリーズのリンク
入口ページ  /aoi/
   ↓  「何に困っているか」で分岐
比較ページ  /aoi/sim/ ・ /aoi/hikari/ ・ /aoi/wifi/
   ↓  各社の「公式サイトで確認する」ボタン
ASP案件（各社の公式サイト）
   ↓
成約
```

### ページごとの中身

#### 入口ページ `/aoi/`

プロフィールから来た人が最初に見る1枚。ここで売り込まない。

1. あおいの一言（**「私が使った」は書かない**。「調べてまとめました」）
2. **AIキャラであることの明示**（隠さず最初に書く）
3. **広告・アフィリエイトであることの明示**
4. 3つの入口ボタン
   - スマホ代を下げたい → `/aoi/sim/`
   - 家のネットを見直したい → `/aoi/hikari/`
   - 工事なしでネットを使いたい → `/aoi/wifi/`
5. 「条件から選ぶ」への導線 → `/aoi/select/`
6. 更新日と、価格は各社公式が正である旨

#### 比較ページ `/aoi/sim/`（本命）

**客観比較型。一人称の体験談は1文字も書かない。**

比較表の列（`offers.json` にある項目だけで作れるもの）:

| 列 | データの有無 |
| --- | --- |
| 月額料金 | ○ 8社ぶんある |
| データ容量 | ○ 8社ぶんある |
| 初期費用 | ○ 8社ぶんある |
| 契約期間の縛り | ○ ある |
| キャンペーン・キャッシュバック | ○ ある（LIBMO 23,000円など） |
| メリット | ○ ある |
| デメリット | ○ ある（★必ず載せる） |
| 向いている人 | ○ ある |
| **通話オプション** | **× 2社分しかない → 要調査** |

表の下に「条件から選ぶ」ブロック：

- とにかく安くしたい → 月額の安い順
- 動画をよく見る → 容量の多い順
- 通話が多い → （通話データを埋めてから）
- 初期費用を抑えたい → 初期費用0円のもの
- キャッシュバック重視 → 金額の大きい順

★**書いてはいけない表現**は `offers.json` の `ng_phrases` に各社ぶん
入っている（例:「日本一速い」「絶対つながる」）。これを機械で弾く。

#### 注意書きページ

- `/aoi/about/` … あおいはAIが作ったキャラであることの説明
- `/aoi/disclosure/` … 広告・アフィリエイトの明示
- 特商法・プライバシーポリシーは既存（`affiliate/legal.html` `privacy.html`）を流用

### ★守る書き方のルール（機械で検査する）

| 禁止 | 例 |
| --- | --- |
| 一人称の使用体験 | 「私が使った」「私はこれに変えた」「乗り換えました」 |
| 未確認の金額 | 「月7,000円浮いた」「◯円安くなった」 |
| 断定・誇大 | 「必ず安くなる」「絶対おすすめ」「日本一」 |
| 煽り | カウントダウン、「今だけ」、根拠のない二重価格 |

事実を書くときは **出典URLと確認日をセットで持つ**（あとで古くなったと
分かるように）。

## 2. 必要なURL構造

### ページ

| URL | 中身 |
| --- | --- |
| `/aoi/` | 入口。プロフィールリンクの行き先 |
| `/aoi/sim/` | 格安SIM比較（本命） |
| `/aoi/hikari/` | 光回線比較 |
| `/aoi/wifi/` | ポケットWiFi・工事不要 |
| `/aoi/select/` | 条件から選ぶ |
| `/aoi/about/` | AIキャラであることの説明 |
| `/aoi/disclosure/` | 広告表示について |

**すべて相対リンクで作る。** そうすれば `/aoi/` フォルダを
そのまま独自ドメインの直下へ移すだけで引っ越せる。

### 流入元の記録（UTM）

| 項目 | 入れる値 |
| --- | --- |
| `utm_source` | `instagram` / `x` / `tiktok` |
| `utm_medium` | `bio`（プロフィールリンク） / `story`（ストーリーズ） / `post` |
| `utm_campaign` | `aoi`（固定） |
| `utm_content` | `post_001` 〜 `post_030` / `bio` |

例：
```
/aoi/?utm_source=instagram&utm_medium=story&utm_campaign=aoi&utm_content=post_005
```

### ★ここが実務上いちばん大事な点

**Instagramの投稿本文にURLを書いてもリンクになりません。**
プロフィールのリンクは1本しか置けないので、そこは
`utm_content=bio` に固定されます。

**投稿1本ごとの成果が分かるのは、ストーリーズのリンクだけです。**
つまり「どの写真・どのCTAが効いたか」を測りたいなら、
フィード投稿と同時にストーリーズを出し、そこに
`utm_content=post_005` 付きのリンクを貼る運用が必須になります。

Xは本文にURLを直接置けるので、投稿ごとの計測はそのままできます。

## 4. KPI設計

### 測る場所

| 段階 | どこで測るか | 記録する内容 |
| --- | --- | --- |
| ① 表示 | Instagram / X の管理画面（手で記録） | リーチ数 |
| ② プロフィール訪問 | 同上 | プロフィール表示数 |
| ③ 入口ページ到達 | GA4 の `aoi_entry` | utm_source / utm_content 別 |
| ④ 比較表の閲覧 | GA4 の `compare_view` | どの比較ページか |
| ⑤ 案件クリック | GA4 の `offer_click` | どの会社・表の何番目か |
| ⑥ 成約 | **ASPの管理画面** | ★下記の問題あり |

### ★成約が今は測れない

`affiliate/data/tracking_config.json` の `asp_conversion_tags` が
a8net / afb / felmat / valuecommerce **4つとも空**です。
このままだと「クリックまでは分かるが、売れたかどうかが分からない」。

また既存LPにはクリック計測がほとんど入っていません
（クリック計測用の印は0か所）。**あおいのLPには最初から入れます。**

### 数字の目標は、いま置きません

実測がゼロの状態で「クリック率◯%を目指す」と書いても、
根拠のない仮定にしかならず、達成しても失敗しても意味が読めません。

代わりに、**自動投稿へ進んでよいかの線**を決めておきます。

30日を手で回したあと、次の3つが全部そろったら自動化へ進む：

1. 入口ページへの到達が、投稿由来だと確認できている（UTMで裏が取れる）
2. 案件クリックが発生している（0ではない）
3. **成約が1件以上、ASP管理画面で確認できている**

1つでも欠けたら、自動投稿は作らない。作っても増えるのは投稿数だけで、
売上は増えないためです。
