# influencer ／ 健全なAIインフルエンサー（あおい ほか）

作成 2026-08-31。**成人向け写真集とは完全に別事業です。**

## このフォルダは何か

節約・ひとり暮らしを発信するAIキャラ「あおい」を中心に、SNS投稿と
リール動画を作る場所。**SNS・広告・アフィリエイトに出る側**。

以前は `ai-influencer/` の中で、成人向け（R-18）写真集と同じ場所に
置かれていた。1枚でも混ざるとアカウント凍結・提携解除・決済停止に
つながるため、2026-08-31 にこちらへ引き上げた。

## ★絶対のルール

**このフォルダと `ai-influencer/`（成人向け写真集の工房）を、
どんな形でも接続しない。**

| 分ける対象 | 健全側（ここ） | 成人向け側 |
| --- | --- | --- |
| フォルダ | `influencer/` | `ai-influencer/` |
| SNSアカウント | あおい専用 | 作らない・持たない |
| ドメイン／LP | あおい専用の入口 | 別。共有しない |
| メールアドレス | 専用 | 別 |
| 決済・受け取り口座 | 専用 | 別（Wise/PayPalはアダルト禁止） |
| 画像エンジン | 共用（下記） | 共用（下記） |

画像エンジン（ComfyUI・33GB）だけは、1台のマシンに1つしか置けないので
`ComfyUI` という参照（ショートカット）で共用している。ただし
**素材が行き来しないよう、下記の歯止めが入っている。**

## 機械の歯止め

`isolation_guard.py` が、投稿パック・リール動画が読み込むフォルダを検査する。

- 成人向けを示す言葉（photobook / censored / mosaic / _pack / fanza など）を含むと止まる
- このフォルダの外を指していると止まる
- フォルダを通しても、画像1枚ずつでもう一度確かめる（二重の歯止め）

効くことは、わざと破って確認済み：

```
python3 隔離ガードを試す.py
```

→ 10通りの破り方を試して 10/10 で止まる／通すべきものは通る。

`.gitignore` で `ai-influencer/` を丸ごと除外済み。このリポジトリの
ルートは Vercel へ公開される営業LPサイトなので、`git add -A` をしても
成人向けが1件も入らないことを確認済み。

## いま入っているもの

- `output/` … あおいの写真 15枚（`aoi_01`〜`aoi_15`）
- `post_packs/` … 投稿パック（2026-06-29 分の15本）
- `reels/` … リール動画
- `persona.json` … あおいの設定と誘導先（**`link_url` が空のまま**＝LPが未確定のため）
- `cta_settings.json` … 媒体（X / Instagram / TikTok）ごとの誘導のしかた
- `aoi_link_map.json` … 投稿 → LP → ASP案件 の対応関係
- `link_builder.py` … 誘導先URLの受け渡し・UTM付け・媒体別CTA
- 他キャラ（ひなた・ルナ・ミオ・ガチャ・serene）の設定と写真

## 誘導リンクの使い方（2026-09-01 実装）

投稿本文にURLを直書きしない作りにしてある。本文には目印 `{{CTA}}` だけを置き、
媒体ごとに後から差し替える（Instagram・TikTokは本文のURLがリンクにならないため）。

```
# 誘導先・UTM・対応表だけ確認する（AIを呼ばない＝料金がかからない）
python3 make_post_pack.py --下見 --link-url "https://（LPのURL）/"

# 日常投稿だけ作る（誘導先が未定でも動く）
python3 make_post_pack.py --広告なし
```

★`link_url` が空・仮の値（example.com など）だと、**AIを呼ぶ前にその場で止まる。**
仮URLは作らない（作ると、どこにもつながらない投稿が量産されるため）。

LPのパスは `aoi_link_map.json` に**相対**（`sim/`）で書く。こうしておくと、
あとで独自ドメインへ引っ越しても `link_url` を差し替えるだけで全リンクが直る。

## LPの作り直し方

比較データ（`affiliate/data/aoi_sim_compare.json`）を直したら：

```
python3 build_aoi_lp.py            # 作り直す
python3 build_aoi_lp.py --検査だけ  # 表現の検査だけ
```

景表法・FTCで問題になる言葉（「業界最安」「乗り換えました」など）が
1つでも入っていると、**書き出す前にその場で止まる。**
