# ai-products ─ 中小事業者向けAIプロダクト（BtoB販売用）

STAGE UP（法人営業LP）から売る、店舗・現場向けの実用AIツール群。
第1号は「**AI返信パック**」。口コミ・問い合わせ・クレーム一次対応の返信文をAIが下書きする。

## 収録物

| ファイル | 役割 |
|----------|------|
| `reply-pack.js` | 返信パック本体（CLI）。`--type=review/inquiry/complaint` の3機能。 |
| `review-reply.js` | 口コミ返信のみの単体版（初号機・デモ用に残置）。 |
| `../api/reply.js` | ブラウザ用サーバーレスAPI（Vercel `/api/reply`）。上記と同じ指示・NGチェックを流用。 |
| `../ai-reply-pack.html` | 商品LP＋その場で試せる入力フォーム（`/ai-reply-pack`）。 |
| `AI返信パック_使い方マニュアル.md` | 納品時にお客様へ渡す手順書。 |
| `BtoB営業提案文.md` | 提案メール／DM／電話トークの下書き集（送信は人が判断）。 |

## 3つの機能

- **review**：Google口コミ返信（【丁寧】【親しみ】【簡潔】）
- **inquiry**：問い合わせメール返信
- **complaint**：クレーム一次対応（【丁寧・低姿勢】【冷静・事実確認】【簡潔】）

いずれも「業種」「希望の雰囲気」を任意で渡すと文体を寄せられる。

## 使い方（CLI）

```
node ai-products/reply-pack.js                                   # 口コミのデモ
node ai-products/reply-pack.js --type=inquiry  --shop="工務店ABC" --text="外壁塗装の見積もりが欲しい"
node ai-products/reply-pack.js --type=complaint --shop="整体ここち" --text="30分待たされた"
```

APIキーは環境変数 `ANTHROPIC_API_KEY`、無ければ `../gorogoro-growth/.env` → `../automation/.env` から読む（値はコードに書かない）。

## 使い方（ブラウザ）

`/ai-reply-pack` の「この場で、返信案をためす」フォームから利用。
裏で `/api/reply`（POST: `type/shop/stars/genre/tone/text`）を呼ぶ。

## 本番公開の手順

1. Vercelのプロジェクト環境変数に `ANTHROPIC_API_KEY` を設定（未設定だと「キー未設定」エラー）。
2. デプロイ（公開はユーザー判断で実施）。
3. 公開後、Anthropic側で**Spend上限**を設定しておくと安心（`/api/reply` は簡易レート制限を持つが、サーバーレスのため完全ではない）。

## 安全設計（景表法／医療広告セーフ）

- システム指示で断定・誇大・優良誤認（「必ず」「絶対」「日本一」「完治」「100%」「確実」等）を禁止。
- 生成後に `NG` 配列で二重チェックし、該当時は画面/CLIで警告。
- 効果・効能の保証や来店強要はしない。**最後は人が確認して送信**する前提。
- 価格は通常価格のみ・二重価格や煽りカウントダウンは使わない。

## 料金（対外・通常価格のみ）

- 初期 ¥30,000 ／ 月額 ¥9,800（税抜）・最低契約6ヶ月。

## 注意

- `.env` / secrets はコミットしない。キーの値は出力・レスポンスに一切出さない。
- ココナラでの所得・副業系サービス出品は規約/景表法リスクで不可。出品するならランサーズ等。
- 特商法・運営元表記の実ページ化には正式な事業者情報が必要（未確定のため要確認）。
