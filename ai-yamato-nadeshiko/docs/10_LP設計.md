## 0. ★この設計は途中で一度ひっくり返っている

当初は「**Xから来た人を最適な案件へ即リダイレクトする薄い1枚**」で設計していた。
**43社のASP調査で、この形は成立しないことが分かった。**

| 会社 | 一次情報で確認した条件 |
|---|---|
| Booking.com | **SNSのみのpublisherを明示的に拒否** |
| GetYourGuide | 編集コンテンツを持つ媒体であることが条件 |
| JapanesePod101 | **アクティブなサイトが審査条件**（SNSプロフィールだけでは不可） |
| Amazon Associates US | 許可媒体の一覧に**Xが無い** |

→ **審査で見られているのは国籍ではなく「媒体の実体」。**
→ **中身のない転送ページは、審査に落ちるだけでなく、落ちた理由が事業の根幹に当たる。**

**したがってLPは「読む価値のある英語ページ」でなければならない。**
ただし**巨大なLPにはしない**（ユーザー指示）。**中身のある1枚**、が答え。

| # | ブロック | 中身 | 必須理由 |
|---|---|---|---|
| 1 | ヘッダー | サイト名・Suzuho Awanoの写真1枚 | — |

| 5 | 案件リンク | 比較表の中から、その国で使える案件へ | — |

### 本文の書き方（Suzuho Awanoの実使用経験を書かない）

**AIキャラの広告利用自体は禁止されていない。禁じられるのは虚偽・偽装の推薦や体験談。**
Suzuho Awanoは実使用経験を持たないため、使用・購入・旅行の経験として書いた時点で虚偽になる。

| ✕ 禁止 | ⭕ 置き換え |
|---|---|
| `I used this eSIM in Kyoto and it worked well.` | `An eSIM does not require picking up a device at the airport.` |
| `This is the best option.` | `This option has the lowest price for a 7-day stay. (source, checked 2026-08-22)` |

**構成に使う型**: 客観的機能紹介 / 商品比較 / 料金比較 / 選び方 / FAQ / Japan Travel Tips / Features / Pros・Cons。

**全ての事実主張に `source_url` と `checked_at` を持たせる。**
価格・キャンペーンは **30日**、規約・法令は **90日** を超えたら、再確認するまでページに出さない（`OUTDATED_SOURCE`）。

## 2. 技術構成

| 項目 | 採用 | 理由 |
|---|---|---|
| ホスティング | **Cloudflare Pages + Functions** | 無料枠で足りる。**既存Vercel（STAGE UP本体）を一切触らない** |
| 国判定 | **`request.cf.country`** | 追加費用ゼロ。GeoIP APIを契約しない |
| データ保存 | **Cloudflare D1**（クリックログ） | 母艦のlibsqlへ日次で同期 |
| ドメイン | 独立ドメイン（Phase 0で候補確保） | **既存事業のドメインと絶対に混ぜない** |
| 静的部分 | HTML＋CSSのみ。JSフレームワークを使わない | 表示速度がランキング要因（検証済み原則） |

```
lp/
├── functions/
│   ├── _middleware.js   # 国判定・クリックID発行・ログ記録
│   └── go/[slug].js     # 案件リダイレクト（302）
└── public/
    ├── index.html
    ├── privacy.html
    └── style.css
```

**ブランドカラーは4色だけ**（`01_CHARACTER/SUZUHO_AWANO_PROFILE.md` §3）: `#26456E` / `#F5F0E6` / `#C1552E` / `#2B2B2B`。

## 3. 計測パラメータ（UTM）

Xの投稿に載せるURLの形:

```
https://<ドメイン>/?utm_source=x
                  &utm_medium=social
                  &utm_campaign=<キャンペーン名>
                  &utm_content=<A|B>        ← EXP-001の群
                  &post_id=<posts.id>
                  &character=hana
                  &content_type=<カテゴリ>
```

| パラメータ | 中身 | 用途 |
|---|---|---|
| `utm_source` | `x` 固定 | 流入元 |
| `utm_medium` | `social` 固定 | — |
| `utm_campaign` | 案件・企画名 | 案件別の効果 |
| **`utm_content`** | **`A` / `B`** | **EXP-001の群。これが無いと実験が成立しない** |
| **`post_id`** | `posts.id` | **どの投稿から来たか。全ての分析の起点** |
| `character` | `hana` 固定 | 将来2人目を出したときの識別 |
| `content_type` | 10カテゴリのどれか | カテゴリ別の集客力 |

### サーバー側で必ず記録するもの（ユーザーに入力させない）

| 項目 | 取得元 |
|---|---|
| **Country** | `request.cf.country` |
| **Device** | `User-Agent`（mobile / desktop / tablet の3分類だけ） |
| **Referrer** | `Referer` ヘッダ |
| Campaign | クエリ |
| Post ID | クエリ |
| click_id | **サーバーで発行**（UUID）。案件リダイレクト時に引き渡す |

## 4. Cookie・プライバシー・GDPR

| 項目 | 決めごと |
|---|---|
| **自前のCookie** | **使わない。** click_id はURLで引き回す |
| **アクセス解析Cookie** | **使わない**（GA4を入れない） |
| **同意バナー** | **不要にする設計**（Cookieを置かないため） |
| ASPのCookie | リダイレクト先（ASP側ドメイン）で発行される。**当方は関与しない**旨をPrivacyに明記 |
| IPアドレス | **保存しない。** 国コードだけを保存する（`request.cf.country` は生IPを保存せずに取れる） |
| Privacyページ | 「何を記録し、何を記録しないか」を英語で明記。運営者名・連絡先を書く |

**Cookieを置かない構成にする理由**: EU圏へ配信するため、同意バナーを出すと**リンククリックの前に1ステップ増える**。
**国コードとリファラだけなら同意なしで扱える範囲に収まる。** 計測精度より、離脱を減らす方を取る。

> ★これは `DECISION` であって法的助言ではない。**公開前に一度、内容を人間が確認すること。**

## 5. リダイレクトの動き

```
X投稿のリンク
  → LP（index.html）※ここで比較を読む
  → 案件リンクをクリック
  → /go/<slug>?click_id=...&post_id=...
  → functions/go/[slug].js
       ・国コードで使える案件を選ぶ
       ・clicks テーブルへ1行書く
       ・ASPのトラッキングURLへ 302
```

**LPを素通りさせる自動リダイレクトはしない。** 素通りさせると §0 の「媒体の実体」が消える。

**国別の出し分けは「並び順」まで。** ある国で使えない案件は非表示にするが、
**勝手に別案件へ差し替えない**（`AUTO_OFFER_CHANGE=false`）。

## 7. やらないこと

- 巨大なセールスLP（指示: 最小構成）
- 収益額の訴求（`月10万円が狙えます` 等）→ **景表法（優良誤認）**
- カウントダウン・在庫煽り → 検証済み原則で禁止
- Suzuho Awanoの一人称体験談 → FTC
- 自動リダイレクト（LP素通り）
- GA4・Cookie同意バナー
- 既存ドメイン（gorogorogacha.com 等）への相乗り
