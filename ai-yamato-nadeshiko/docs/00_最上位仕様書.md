## 1. 絶対原則（違反したら止める）

### 1-1. 二重ロック（外部副作用は既定で全部OFF）
```
AUTO_X_POST=false            # X本番投稿
AUTO_AFFILIATE_APPLY=false   # ASP申請
AUTO_OFFER_CHANGE=false      # 案件の差し替え
AUTO_CONTENT_PUBLISH=false   # LPの公開
```
- 上記4つは既定false。trueにするのは、人間が明示的に許可したときだけ。
- さらに実行直前に「対象アカウント名の照合」を行う。想定と違えば実行しない。
- 実装の存在しない副作用（課金・ASPへの自動応募）は、コードごと書かない。

### 1-2. 数字を作らない
- 取れなかったデータを0にしない。「未取得」と「0」を必ず区別する。
- 最低サンプル数に満たないうちは、勝敗の結論を出さない（`CONTINUE` のみ）。
- 推測値を実測値と同じ場所に保存しない。

### 1-5. 事実と仮説を混ぜない（全ドキュメント共通）
全ての記述に、次の5分類のいずれかを付ける。分類のない断定は書かない。

| 分類 | 意味 | 扱い |
|---|---|---|
| `FACT` | 一次情報（公式ドキュメント・公式ヘルプ・法令原文）で確認済み | `checked_at` と出典URL必須 |
| `HYPOTHESIS` | もっともらしいが未検証。二次情報・推測を含む | Experimentを立てるまで判断に使わない |
| `ASSUMPTION` | 計算のために置いた前提値（CVR 2%など） | 実測が出たら必ず差し替える |
| `EXPERIMENT` | 検証中。開始日・最低サンプル数・評価指標を持つ | 途中経過で結論を出さない |
| `DECISION` | 上記を踏まえて人間が決めたこと | 決めた日と理由を残す |

**一度調べた数字を恒久ルールにしない。** 規約・料金・アフィリ条件は `checked_at` が無ければ無効として扱い、再確認する。

### 1-3. 表現規制（景表法・全事業共通）
- 「必ず稼げる」「絶対」等の断定・誇大はNG。
- 二重価格・カウントダウン等で購入を急がせない。
- これはLP・X投稿・広告文の全部に適用する。

### 1-4. 既存事業に触れない
- 新規独立プロジェクト。ルートの `vercel.json`、`affiliate/`、`aura/` 等の既存ファイルを改変しない。
- 既存Xアカウント（@gorogoro_gacha / @KIKUSORA_gacha）とは完全に別系統。認証情報も別に持つ。

## 2. 調査で判明した「設計を変えるべき5点」

調査（2026-08-22実施、出典は `03_調査_X規約とAPI.md` / `02_調査_海外アフィリエイト.md`）の結果、
当初構想のままでは事業が成立しない箇所が見つかった。以下の形に変更する。

### 変更1. 主収益源をアダルト系CPAから「日本文化・旅行・通信・日本商品」へ入れ替える
理由は3つ、いずれも致命的。
1. **Xの集客が死ぬ**: センシティブラベルを付けた瞬間、For You・検索・トレンド・おすすめ通知の全部から除外される。閲覧側もデフォルトOFF。「海外の新規ユーザーにリーチしてLPへ送る」というモデルが構造的に成立しない。[X公式ヘルプ Adult Content]
2. **お金が着金しない**: Wiseは規約でアダルト全面禁止、PayPalもデジタル性的商材は不可。日本在住だと国際電信送金（最低$500）か暗号資産しか残らない。月10万円規模だと初回入金まで数ヶ月かかる。
3. **刑法175条**: 海外サーバー・海外向けでも、日本から閲覧可能なら国内犯として処罰可能という最高裁判断がある。2025年に生成AIのわいせつ画像で実際に逮捕例が出ている。

→ **表のXアカウントとLPは、露出も性的示唆も一切含まない「日本文化」路線で純粋に運用する。**
→ アダルト系案件は当面採用しない。将来やるなら完全に別法人・別ドメイン・別導線で、本OSからは切り離す。

### 変更2. Suzuho Awanoが「AI生成キャラクター」であることを最初から公表する

**正確に書く。「XがすべてのAIキャラに開示を義務付けている」わけではない。**

| 分類 | 内容 |
|---|---|
| `FACT` | Xが禁止しているのは **AI生成のプロフィールを使った欺瞞的ななりすまし**（fake personas / deceptive impersonation）。「AIキャラ全般の開示義務」という条文ではない |
| `FACT` | EU AI Act 第50条の透明性義務は **2026-08-02から適用開始済み**。EU圏へ配信するなら、これが実際に拘束力を持つ根拠 |
| `FACT` | Xには「Automated Account（自動アカウント）」ラベルの規定がある。API経由の自動運用に進む場合はこれの検討が必要 |
| `DECISION` | 上記を踏まえ、**最初からプロフィールに `AI-generated Japanese virtual creator`（または同等の意味）を自然な文で表示する** |

やらないこと（絶対）:
- Suzuho Awanoを実在女性のように偽装する
- 実在人物の名前・顔・経歴を使う／学習させる

→ 隠すのではなく、**「日本のAIが作った大和撫子」であること自体をブランドにする。**

### 変更3. リンクの置き場所は「仮説」として30日A/Bで検証する

**確定しているのはAPIコスト差だけ。リーチ差は未検証。**

| 分類 | 内容 |
|---|---|
| `FACT` | X API従量課金: URLを含む投稿 **$0.20/件**、含まない投稿 **$0.015/件**。約13倍差。ただし後述の通り、**この差はリンク配置の判断材料にはならない** |
| `HYPOTHESIS` | 「外部リンク付き投稿はリーチが30〜50%落ちる」。公開アルゴリズムのソース由来の二次情報で、ペナルティ撤廃報道もあり **矛盾している**。事実として扱わない |
| `EXPERIMENT` | EXP-001（下記）で30日測る。**最低サンプルに達するまで結論を出さない** |

**EXP-001: リンク配置A/B**

| | A案 | B案 |
|---|---|---|
| 本文 | リンクなし（画像＋英文のみ） | 本文に直接リンク |
| リンク | 自分のリプライにぶら下げる | — |
| API課金 | 本体$0.015 ＋ リプライ$0.20 ＝ **$0.215** | **$0.20** |

**★ここで当初の想定が1つ崩れた（Cost Simulatorを実際に回して判明）**

「リプライに逃がせばAPI費が13分の1になる」は **誤り**。
リンクを1本届けるのに必要な費用は **A案 $0.215 > B案 $0.20** で、**A案の方がわずかに高い**。
13倍差が効くのは「そもそもリンクを載せない投稿」であって、リンクを載せる投稿では効かない。

→ したがって **A案を選ぶ理由はコストではなくリーチしかない。**
→ そのリーチ差が `HYPOTHESIS` である以上、**A案を既定にする根拠は現時点で存在しない。** だからA/Bで測る。

評価指標（9つ全部を1万表示あたりで比較する）:
Impressions / Profile Views / Engagement Rate / Link Click / CTR / Affiliate Click / Conversion / Revenue / **RPM**

- **利益計算にはAPIコストを必ず引く。** RPMは「(収益 − API費) ÷ 表示 × 1000」で比較する。
- 最低サンプル数に届かない間の出力は `CONTINUE` のみ。片方に寄せない（A/B各50%配分を維持）。
- 検算: `npm run cost -- --exp001 --posts 90 --link-posts 30 --metric-reads 720`

### 変更4. ランディングページは Cloudflare Pages + Functions に置く
- 国別出し分けに必要な国判定が `request.cf.country` で無料・エッジで即取れる。
- 既存のVercel「STAGE UP」プロジェクトの認証ゲートに一切触らずに済む。
- クリックログをD1（SQLite）に同じ場所で持てる。
- ただしLPは中身のあるページにする。実質リダイレクトだけのページは「想定外の遷移先へ飛ばすリンク」としてXにブロックされ得る。

### 変更5. Xの成果データは30日で消えるので毎日吸い上げる
- リンククリック数・プロフィールクリック数（non_public_metrics / organic_metrics）は **投稿から30日間しか取得できない**。31日目以降は永久に取れない。
- → 毎日バッチで自社DBへ保存する。ここを落とすと学習データが二度と復元できない。

## 3. 収益源の優先順位（この順で着手する）

| 順 | 収益源 | 採用理由 |
|---|---|---|
| 1 | 日本旅行系（Klook eSIM 20% / GetYourGuide 8%） | ブランドと商材が完全一致。Wise/PayPalで着金でき、法務リスクゼロ |
| 2 | VPN（NordVPN等 初年40%＋更新30%リカーリング） | サイト不要・SNSのみで申請可能、審査ハードルが最も低い |
| 3 | 日本商品（Bokksu / Sakuraco 等の和菓子サブスク） | 「日本文化」の文脈で最も自然に紹介できる |
| 4 | Amazon Associates（US） | 和雑貨・和装小物。ただし受取にUSD口座が必要 |
| 5 | LosPollos（Smartlink） | 公式FAQでソーシャル流入を明示許可。週次$100払い。※非アダルトオファーに限定して使う |

不採用: CrakRevenue・AWEmpire・AdCombo・ExoClick（理由は `02_調査_海外アフィリエイト.md` 参照）。

## 4. AIの役割分担（8体）

| AI | 仕事 | 出力 |
|---|---|---|
| Research AI | 案件の発掘・条件の記録 | offers テーブル |
| Offer AI | 案件を0〜100点で採点し国別に並べる | offer_scores |
| Character AI | Suzuho Awanoの一貫性維持・生成画像の顔照合 | character_qa |
| Content AI | 投稿案・画像案・動画案の生成 | posts(draft) |
| English AI | 「日本人女性の一生懸命な英語」に調整 | posts.text |
| Growth AI | 投稿時間・テーマ・国の配分最適化 | experiments |
| Revenue AI | クリック→CV→利益の分析 | reports |
| Compliance AI | X規約・ASP規約・景表法・AI開示の事前チェック | compliance_checks |

- 全AIの出力は構造化JSONでDBに保存し、他のAIが参照できるようにする。
- Compliance AI のチェックを通っていない投稿は、承認画面に出さない。

## 5. 月10万円の逆算（保証はしない。不足KPIを探すための道具）

```
月間X表示        1,500,000
  ↓ プロフィール/リプライ経由クリック率 1.5%
LPクリック          22,500
  ↓ LP → アフィリンク遷移 50%
アフィリクリック    11,250
  ↓ CVR 2%
成約                  225件
  ↓ 平均報酬 ¥600（Klook eSIM 20%想定）
売上              ¥135,000
```
- VPN（1件あたり約¥2,800）が混ざれば、必要成約数は大きく下がる。
- 10万円に届かないとき、AIは「表示・クリック率・LP・案件・国」のどこが原因かを、この式の各段で判定する。
- **この式は目標であって約束ではない。達成を断定する表現をLPや対外資料に書かない。**
