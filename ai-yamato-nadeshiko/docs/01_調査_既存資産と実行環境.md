## 8. 分析・学習の型 → `ai-commerce-os/lib/shadow.ts` の型を採用

DBは全プロジェクトで **libsql/SQLite（`@libsql/client`）** に統一されている。本件もこれに合わせる。

4つの原則（既存実装から抽出）
1. **判断した瞬間の前提を凍結する** — 答え合わせ予定（7/30/90日後）を判断時に先に3行作る。都合のいい期間だけ見て「当たった」と言えなくする
2. **少ない実績で点数を動かさない** — 件数に応じて補正の効きを NONE 0 → WEAK 0.3 → MID 0.6 → FULL 1.0、上限±10点
3. **取れないデータを0点にしない** — 「未評価」と「0点」を分ける
4. **結論の手順を固定する** — HYPOTHESIS→TEST→OBSERVATION→RESULT→DECISION の順にしか進めず、最低サンプル数未満なら CONTINUE 以外を返さない

DB接続は `fanza-affiliate/lib/db.ts`（WAL + `busy_timeout=60000`）をコピーする。
