## A. 料金：2026年2月にティア制が廃止、従量課金へ

**Free / Basic / Pro は新規加入できない。** 新規開発者は従量課金（pay-per-usage）が唯一の選択肢。
既存契約者のみグランドファザリングされ、Basicは2026年6月1日から自動移行が開始。
[一次] https://docs.x.com/x-api/getting-started/pricing

### 単価（一次確認済み）
| 操作 | 単価 |
|---|---|
| 投稿作成 | **$0.015** |
| **URLを含む投稿** | **$0.200**（通常の13.3倍） |
| DM / ユーザー操作 | $0.015 |

### ★実績データは30日で消える（設計に直結）
| メトリクス | 取れる項目 | 認証 | 期間 |
|---|---|---|---|
| public_metrics | retweet, quote, like, reply, **impression_count**, bookmark | Bearer | 制限なし |
| **non_public_metrics** | **url_link_clicks**, **user_profile_clicks**, engagements | ユーザーコンテキスト | **過去30日のみ** |

[一次] https://docs.x.com/x-api/fundamentals/metrics

### ★費用は「プラン月額」ではなく従量。Cost Simulatorで都度計算する

**2026年2月にティア制（Free/Basic/Pro の月額プラン）は廃止され、従量課金へ移行した。**
したがって「X APIは月額◯円」という固定表現は使わない。**実際の投稿数・Read数から毎回算出する。**

確定単価 `FACT` / checked_at 2026-08-22:

| 課金対象 | 単価 |
|---|---|
| Content Create（URLなし） | **$0.015 / request** |
| Content Create（URLあり） | **$0.20 / request** |
| Owned Read（自分の投稿の実績取得） | **$0.001 / resource** |

計算式:
```
月額USD = (URLなし投稿数 × 0.015)
        + (URLあり投稿数 × 0.20)
        + (実績取得したリソース数 × 0.001)
```

シミュレータ: `npm run cost -- --posts 90 --link-posts 90 --metric-reads 900`
（実装: `scripts/cost-simulator.ts`。詳細と入出力例は `08_コストと収益モデル.md`）

**予算超過時は警告を出すだけ。自動で投稿数を絞ったり停止したりしない。**
検証期間中に勝手に本数が変わると、A/Bの比較条件が崩れてデータが無駄になるため。

## B. 自動化ルール

| 行為 | 可否 |
|---|---|
| 公式API経由の自動投稿・予約投稿 | ⭕ 可 |
| AI生成文を自分のタイムラインへ投稿 | ⭕ 可 |
| AI生成の自動リプライ | 🔺 **Xの事前承認が必要** |
| 自動いいね | ❌ 禁止 |
| 一括・攻撃的・無差別な自動フォロー/アンフォロー | ❌ 禁止 |
| キーワード検索を起点とした自動返信・自動メンション | ❌ **明確に禁止** |
| 同一・類似内容の連投（1アカ内も複数アカ間も） | ❌ 禁止 |
| 複数アカウントの重複・実質同一運用 | ❌ 禁止 |
| トレンドへの自動投稿 | ❌ 禁止 |
| ブラウザ自動操作・スクレイピング・非公式API | ❌ **永久凍結** |

自動リプライの唯一の許可条件:「受信者が事前にX上で連絡を受ける意思を明確に示している」こと。
**フォローされただけでは同意にならない。** 1つの投稿・1つのオプトインに対して2回以上返信しない。
[一次] https://help.x.com/en/rules-and-policies/x-automation / https://docs.x.com/developer-guidelines

### ★Botラベルの表示義務（見落としやすい）

2. **bioに自動アカウントである旨と運営者を明記**（例: `Bot by @xxx`）
3. **人間が管理するアカウントへリンク**

[一次] https://docs.x.com/developer-guidelines

### 凍結されやすいパターン
2026年3〜4月、Xは「inauthentic behavior」を対象とした大規模BANウェーブを実施。
フォロワー1,000〜50,000のアカウントが最も影響を受け、正規ユーザーも巻き込まれた [二次]。
危険: 短期間の大量フォロー、高頻度投稿、非公式API、エンゲージメント購入、コールドDM。

**2025年4月からアカウント作り直しによるBAN回避（ban evasion）も明確に禁止。**

## C. 成人向けコンテンツ（★この事業の生死を分ける箇所）

Xは合意に基づく成人向けコンテンツを許可しており、**AI生成物も含む**。主要SNSで唯一、通常フィード内で許可。
[一次] https://help.x.com/en/rules-and-policies/adult-content

### しかし、センシティブラベルを付けた瞬間に集客が死ぬ
公式記載の措置:
- **For Youのおすすめから完全に除外**
- **For You / Following タイムライン、おすすめ通知、トレンド、検索結果から除外**
- 最も明示的なものは**検索インデックスから恒久除外**
- 18歳未満および**生年月日未設定のユーザーはクリックしても閲覧できない**
- 閲覧側は**デフォルトOFF**（明示的にオプトインが必要）
- 通常の広告隣接からも除外

**→「海外の新規ユーザーにリーチしてLPへ送る」というモデルの土台（For You・検索・トレンド）がほぼ全部消える。**

### ラベルを付けなかった場合の措置（段階的に重くなる）
1. 投稿削除 → 2. **Xが勝手にアカウント設定を変更** → 3. 増幅の制限・収益化停止 → 4. **永久凍結**

繰り返しの未ラベルは「ポリシー回避」として扱われ、処分が重くなる。

### プロフィール画像・ヘッダーに置けないもの
成人向けコンテンツを「目立つ場所」（プロフィール写真・ヘッダー・ライブ動画・リストバナー・コミュニティカバー）に置くことは**全面禁止**。繰り返しで永久凍結。

Xの定義: 全裸・部分的な裸体、および**明示的または暗示的な**性的行為を描き、性的興奮を引き起こす意図のあるもの。
**「暗示的（implied）」も対象**。清楚・着物路線でも、露出や性的示唆が強い画像は判定に引っかかる。

### 結論
**露出も性的示唆も含まない文化コンテンツとして純粋に維持できるかどうかが、この事業の生死を分ける。**

## D. AI生成の開示

- 2026年1月: Xが「Manipulated Media（加工メディア）」タグを導入
- 2026年2月: **「Made with AI」ラベル**を投稿単位のトグルとしてテスト開始。**現時点では任意の自己申告**
- 報道では「将来的に未ラベルの合成メディアは規約違反として扱われる可能性」が示唆されている

### ★Xが禁止しているのは「欺瞞的ななりすまし」であって、AIキャラ全般の開示義務ではない

**ここを盛って書かない。** Authenticityポリシーの対象は、AI生成の顔で**実在の誰かのように装って人を欺く**行為。

> 「**偽のペルソナ**: 他者を欺く目的で、**AI生成のプロフィール写真**、盗用されたbio、誤解を招くプロフィール情報を使い、**捏造されたアイデンティティ**で破壊的または欺瞞的な行為を行ってはならない」
> 「**実在しない人物になりすますためにコンピュータ生成の人物画像を使うアカウントは、欺瞞的とみなされる**」

[一次] https://help.x.com/en/rules-and-policies/authenticity / checked_at 2026-08-22

### 開示の根拠を分けて理解する

| 根拠 | 何を要求しているか | 分類 |
|---|---|---|
| X Authenticity | 欺瞞的ななりすましの禁止（＝実在女性のように装わなければ抵触しない） | `FACT` |
| **EU AI Act 第50条** | **透明性義務。2026-08-02から適用開始済み。EU圏へ配信するなら拘束力を持つ実質的な根拠はこれ** | `FACT` |
| X Automated Account | API経由の自動運用アカウントはラベルと運営者明記が必要 | `FACT` |
| X「Made with AI」ラベル | 投稿単位。**現時点では任意の自己申告** | `FACT` |

**この事業での決定** `DECISION`:
- プロフィールに `AI-generated Japanese virtual creator`（または同等の意味）を**自然な文で最初から表示する**
- Suzuho Awanoを実在女性のように偽装しない／実在人物の名前・顔・経歴を使わない
- 完全自動運用へ進む段階で「Automated」ラベルを有効化し、bioに運営者を明記する

### PCF（パロディ・論評・ファン）ラベル
対象は「実在する人物・団体を描写するアカウント」。**オリジナルのAIキャラは対象外**と解釈できる。
ただしD項のAI開示は別途必要。

## E. リンクの扱い

### アフィリエイトリンク自体は禁止されていない
ただしXは以下をブロックする:
- 悪質なアフィリエイトリンク
- 想定外の遷移先へ飛ばすリダイレクト

[一次] https://help.x.com/en/safety-and-security/phishing-spam-and-malware-links

### 「リンクを貼るとリーチが落ちる」は `HYPOTHESIS`（事実として扱わない）

集めた情報はすべて二次情報で、しかも互いに矛盾している。**これを根拠に運用を決め打ちしない。**

| 主張 | 出典の質 |
|---|---|
| 公開アルゴリズムのソース上、外部リンク投稿に30〜50%のリーチ減がある | [二次] ブログ解説 |
| Musk発言「外部リンク投稿は50〜90%のリーチ減」 | [二次] 発言の伝聞 |
| 非Premiumが外部リンクを投稿するとエンゲージメント中央値がほぼゼロ | [二次] 個人観測 |
| **ペナルティは撤廃された** | [二次] 報道。**上と矛盾** |

[二次] https://explainx.ai/blog/x-algorithm-open-source-github-elon-musk-2026

**確定しているのはAPI単価の差だけ**（URLあり$0.20 / URLなし$0.015 = 約13倍）。`FACT`

→ **EXP-001 として30日間A/Bで実測する。**

| | A案 | B案 |
|---|---|---|
| 本文 | リンクなし（画像＋英文のみ） | 本文に直接リンク |
| リンク | 自分のリプライにぶら下げる | — |
| リンク1本あたりのAPI課金 | 本体$0.015 + リプライ$0.20 = **$0.215** | **$0.20** |

**★「リプライに逃がすとAPI費が13分の1」は誤り**（Cost Simulatorで検算して判明）。
リプライも1件の投稿なのでURL付き$0.20が課金される。**A案の方が本体投稿分だけ高い。**
13倍差が効くのは「そもそもリンクを載せない投稿」であって、リンクを載せる投稿では効かない。
→ **A案を採る理由はリーチしか無く、そのリーチ差が未検証。だから測る。**

評価指標（9つ全部・1万表示あたりで比較）:
Impressions / Profile Views / Engagement Rate / Link Click / CTR / Affiliate Click / Conversion / Revenue / **RPM**

ルール:
- **最低サンプル数に達するまで結論を出さない**（出力は `CONTINUE` のみ）。途中経過で片方に寄せない
- **RPMは「(収益 − API費) ÷ 表示 × 1000」で比較する。** APIコストを引かずに勝敗を決めない
- 検算コマンド: `npm run cost -- --exp001 --posts 90 --link-posts 30 --metric-reads 720`
- 設計の詳細は `事業Vault/AI YAMATO NADESHIKO/06_EXPERIMENTS/EXP-001_リンク配置.md`

## やってよいこと（10）
1. X公式API（従量課金）経由の自動投稿・予約投稿。費用はCost Simulatorで都度算出する
2. AI生成の投稿文を自分のタイムラインに投稿する（リプライ以外）
3. 「Automated」ラベルを有効化し、bioに自動運用である旨と運営者を明記、人間管理アカウントへリンク
4. bioに「AI生成キャラクター」であることを明示する
5. **リンクは本文でなくリプライに置く**（リーチ減の回避＋API課金が$0.20→$0.015）
6. X → 自社LP（中身のある実体ページ）→ アフィリの構成。短縮URLは使わない
7. **投稿から30日以内に** url_link_clicks / user_profile_clicks / impressions を自社DBへ保存
8. 露出・性的示唆のない文化コンテンツに徹し、センシティブラベルを付けずに済む水準を維持
9. 投稿は毎回、内容・構図・文面を変える（類似連投は明確な違反）
10. AI生成メディアに「Made with AI」ラベルを任意で付ける（将来の義務化に先回り）

## 絶対にやらないこと（10）
1. ブラウザ自動操作・スクレイピング・非公式API → **永久凍結**
2. 自動いいね、一括・攻撃的な自動フォロー/アンフォロー
3. キーワード検索を起点とした自動リプライ・自動メンション
4. AI自動リプライ機能をXの事前承認なしで実装する
5. 同一・類似内容の連投、複数アカウントでの重複運用
6. **AIキャラを実在の人物のように見せて運用する**（fake personas違反）
7. プロフィール画像・ヘッダーに露出や性的示唆のある画像を置く（「暗示的」も対象）
8. 成人向け相当のコンテンツをラベルなしで投稿する
9. 安易にセンシティブラベル運用へ舵を切る（For You・検索・トレンドから完全除外＝集客モデルが崩壊）
10. 凍結されたら新アカウントを作り直す（ban evasion）
