## 0. X API費は「プラン月額」ではない。Cost Simulatorで毎回算出する

**2026年2月にX APIのティア制（月額プラン）は廃止され、従量課金へ移行した。**
したがって「X APIは月額◯円のプラン」という固定表現はこのドキュメント群で使わない。
下の表に出てくるX API費は、すべて**その行に書いた投稿数・Read数から計算した結果**であって、契約の月額ではない。

確定単価 `FACT` / checked_at 2026-08-22:

| 課金対象 | 単価 |
|---|---|
| Content Create（URLなし） | $0.015 / request |
| Content Create（URLあり） | **$0.20 / request** |
| Owned Read（自分の投稿の実績取得） | $0.001 / resource |

```
月額USD = URLなし投稿数 × 0.015
        + URLあり投稿数 × 0.20
        + 実績取得リソース数 × 0.001
```

**シミュレータ**: `npm run cost -- --posts 90 --link-posts 0 --metric-reads 360 --usd-jpy 150`
実装は `scripts/cost-simulator.ts`。投稿本数を変えるたびにこれを回して見積もり直す。

**超過時の扱い（重要）**: 実績が想定額を超えたら **警告を出すだけ。自動停止も自動減便もしない。**
理由: 検証期間中に本数が勝手に変わると、A/Bの比較条件が崩れて30日分のデータが無駄になるため。
止めるかどうかは人間が決める。

## 2. 月10万円の逆算（4パターン）

案件によって必要な数字が全く変わる。**どの案件を主軸にするかが、集客の必要量を決める。**

### パターンA: Klook eSIM 中心（報酬 約600円/件）
```
必要成約         167件
 ÷ CVR 2%
アフィリクリック  8,350
 ÷ LP通過率 50%
LPクリック       16,700
 ÷ X CTR 1.5%
月間インプレッション 1,113,000
```

### パターンB: NordVPN 中心（報酬 約2,800円/件）
```
必要成約          36件
 ÷ CVR 1.5%
アフィリクリック   2,400
 ÷ LP通過率 50%
LPクリック        4,800
 ÷ X CTR 1.5%
月間インプレッション 320,000
```

### パターンC: A・Bの混合（平均報酬 約1,200円/件）
```
必要成約          84件
月間インプレッション 約560,000
```

### パターンD: ブランド案件が入った場合
Aitana López の実績（フォロワー38万で平均月€3,000＝約48万円）から見ると、
**フォロワーが3〜5万規模でも、日本文化・観光系の企業案件が1本入れば月10〜30万円は現実的**。
ただしこれは営業活動であって自動化できない。**システムの目標には入れず、おまけとして扱う。**

### 読み方
- **VPN系（高単価）を1本通せば、必要な集客量が3分の1になる。** 最初にNordVPNを取りに行く根拠。
- パターンAの111万インプレッションは、1日3.7万表示。**AIインフルエンサーとしてはかなり伸びた状態**で、6ヶ月以上を見込むべき。
- 月10万円は「3〜6ヶ月かけて到達する目標」であって、初月に出る数字ではない。

## 4. AIが毎日見る差分

システムは毎日、上の逆算式の各段について「今どこが足りないか」を出す。

```
目標: 月10万円（パターンC想定）
────────────────────────────
月間インプレッション  実績 xxx / 必要 560,000  → 達成率 xx%
X CTR                 実績 x.x% / 必要 1.5%    → 達成率 xx%
LP通過率              実績 xx%  / 必要 50%     → 達成率 xx%
CVR                   実績 x.x% / 必要 2.0%    → 達成率 xx%
平均報酬              実績 ¥xxx / 必要 ¥1,200  → 達成率 xx%
────────────────────────────
最も足を引っ張っている段: ○○
次の打ち手候補: ○○
```

**達成率が最も低い1段だけを改善対象にする。** 全部同時に触ると、何が効いたか分からなくなる。
