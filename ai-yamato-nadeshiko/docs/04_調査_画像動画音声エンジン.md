## C. 法務リスク

### C-1. AIインフルエンサー運用の可否
- **禁止しているサービスは確認できなかった。** 各社が禁じるのは*実在人物*の無同意利用
- **Google**: 「人間だけが作ったと偽って出所を偽装する（欺瞞目的）」を明示禁止 → **AI生成と開示すれば適法、隠せば違反。ここが最大の分岐点**
- **Higgsfield**: AI Influencer Studioを公式提供＝明確に許諾
- **Kling**: 無料プランは商用利用全面禁止。有料プランで商用権付与
- **Midjourney**: API自動化が禁止。年商100万ドル超は上位プラン必須

### C-2. 生成物の権利帰属
| サービス | 帰属 |
|---|---|
| OpenAI | ユーザーが出力を所有、OpenAIが全権利を譲渡 |
| Midjourney | 所有権ではなく広範な商用ライセンス。AI生成部分の著作権は主張不可 |
| Kling | 有料プランで商用利用権 |
| **fal.ai / Replicate** | **ToSに明記なし＝未確認。要書面確認** |
| 日本法 | AI生成物に著作権が成立するには**人間の創作的関与**が必要 |

### C-3. ★ディープフェイク規制（すでに発効している）

**EU AI Act 第50条は 2026年8月2日から適用開始。＝20日前に発効済み。**
- 第50条(4): ディープフェイクを生成・操作するAIシステムの**利用者（deployer）は、人工的に生成・操作された旨を、遅くとも最初に接触した時点で、明確かつ判別可能な方法で開示しなければならない**
- 「ディープフェイク」の定義（第3条60号）: 「**既存の人物、物、場所**、実体または事象に類似し、真正であるかのように誤認させるAI生成コンテンツ」
  - → 架空の女性そのものは「既存の人物」に非該当。だが **京都・実在の神社・実在の旅館は「場所」に該当し得る** ため、開示義務が及ぶ可能性が高い
- 「経済的利益を継続的に得ている者・事業活動として行っている者」はdeployerに該当 → **AIインフルエンサー運用者は義務の対象**
- **EU域外の事業者にも適用**（出力がEU内で使用される場合）
- 芸術的・創作的・虚構的作品の場合、開示義務は「作品の鑑賞を妨げない適切な方法」に軽減される

[一次] https://artificialintelligenceact.eu/article/50/ / https://digital-strategy.ec.europa.eu/en/faqs/transparency-obligations-under-article-50-ai-act

**米国カリフォルニア SB 942（AB 853改正）も2026年8月2日施行**
- 対象は月間100万ユーザー超の大規模生成AI提供者 → **個人事業主の運用者は直接の対象外**
- ただし2027年1月1日からホスティングプラットフォーム義務が追加され、X側の表示要件が強化される見込み

**X の自主規制**
- 2026年3月3日以降、武力紛争のAI動画を未開示投稿すると収益分配から90日停止、再犯で恒久停止
- **閾値超過のコンテンツは自主申告がなくても自動でAI判定フラグが付く**
- 「アカウントの背後にいるのが誰かについてフォロワーを欺く」ことは収益化停止・恒久剥奪の対象

### C-4. 日本法での注意点
- **AI推進法**（2025年成立）は理念法で罰則なし。ただし**法務省が2026年4月、生成AIによる肖像・声の無断利用に関する民事責任の範囲を整理する有識者会議を設置** → 今後ルール化の可能性
- **偶然の実在人物への酷似が最大のリスク**: 「AIが勝手に似せたとしても、投稿した本人が責任を負う」というのが現在の法的解釈
- フォロワーが多いほどパブリシティ権侵害と判断されやすく、無料投稿でも拡散すれば侵害認定例あり

**実務対応（必須ルール化する）**
1. 実在人物の写真を学習素材に一切入れない
2. 公開前に画像検索で類似人物チェック
3. プロフィールに「AI生成キャラクター」と明記
