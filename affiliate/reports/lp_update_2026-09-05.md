**改善理由:** 実リンク最高報酬案件（auひかり¥25,000、BIGLOBE光¥20,000等）を含むニッチ。リサーチレポートで競合のCB訴求額が126,000円から172,000円に膨らんでいることを確認。

**変更箇所: pain_points**

変更前:
```
競合の光回線比較サイトでauひかり経由のキャッシュバックが最大126,000円以上と記載されているのを見かけたが...
```

変更後:
```
競合の光回線比較サイトでauひかり経由のキャッシュバックが最大172,000円以上と記載されているのを見かけたが...
```
→ 競合CB額を実調査値172,000円に更新（リサーチレポート2026-09-05より）

**新規pain_point追加:**
```
このサイトが掲載しているauひかりのCB金額（93,000円相当）は競合サイトの172,000円より低いが、なぜ差があるのか・競合の高額CB表記は有料オプション強制加入などの条件付きではないのか・オプション不要で受け取れる実質的なCB金額を比較したうえで申込窓口を選びたい
```
→ 「信頼性・透明性」による申込阻止不安を解消。数字競争ではなく条件の透明性で差別化

**期待効果:** CB金額の信頼性不安を解消することで、「金額が競合より低いから他のサイトで申し込もう」という離脱を防止。実際の受取確実性訴求でCV率向上を見込む。
