## 3. 変更内容（3ニッチ）

### ニッチ1: `remote_worker`（テレワーク・Web会議落ちない回線）

**変更内容:** primary_appeal の冒頭を更新

**変更前:**
```
「【2026年9月21日：NURO光の最大60,000円乗り換え費用還元キャンペーン...」から始まる
```

**変更後:**
```
「【⚠️2026年9月22日更新｜乗り換えの手続きはすべて代行・NTTへの連絡不要・Web申込だけで完結
（代行範囲は各社により異なる・申込時確認）→光回線の乗り換えをめんどくさくて後回しにしてきた
在宅勤務の方へ：手続きを代行してもらえれば今日からWeb申込3ステップで完了できます
（工事立ち合いのみご自身の対応が必要）】...」として先頭に追加
```

**CV向上への期待効果:**
- 1onepiece.jpのKW「乗り換えがめんどくさい人必見」でファーストビューに到達したユーザーが即座に「解消される」と判断してスクロール継続→アフィリリンク到達率向上
- 後回しユーザー（高CVR層）のバリア解消をLPの先頭に配置することで離脱率低減
- 景表法準拠：「代行範囲は各社により異なる・申込時確認」の注記済み

### ニッチ2: `one_person_room`（一人暮らし即日WiFi）

**変更内容:** pain_points の末尾に1件追加

**追加内容:**
```
「ノジマや家電量販店の比較サイトで『一人暮らしWiFiプロが選ぶ8選』などとして複数のサービスが
紹介されているが、当サイトが工事不要・翌日発送・解約金なし・実リンク確認済みの4条件を満たす
SoftBank AirとZEUS WiFiの2択を推薦している理由は何か・家電量販店推薦サービスと当サイトの
2択を比較したうえで選ぶ必要はあるのか・このサイトの2択提案だけで申し込んで後悔しないか
申込前に確認したい」
```

**CV向上への期待効果:**
- ノジマ・ビックカメラの「8選・15選」ページを見てから当サイトに来たユーザーが「なぜ2択なのか」の疑問を持っているケースへの事前解消
- 選択肢の多さに迷って離脱するユーザーに「2択で十分な根拠」を提示して安心感→クリック率向上
- 申込踏み止め不安（「他にもっと良い選択肢があるのでは」）の直接解消

### ニッチ3: `rental_no_construction`（賃貸工事NG・大家確認不要）

**変更内容:** pain_points の末尾に1件追加

**追加内容:**
```
「競合比較サイトで『工事不要・無制限のWiFi』として据置型ホームルーター（SoftBank Air等）と
持ち運び型ポケットWiFi（WiMAX等）が同列に紹介されているが、賃貸で固定回線の代わりに
自宅専用で使う場合はどちらが通信が安定するのか・外へ持ち出さないならホームルーター型の
ほうが電波安定性が高いのか・ポケットWiFi型（WiMAX）は自宅で据置利用しても通信品質が
据置専用型と比べて劣るケースはあるのか申込前に確認したい」
```

**CV向上への期待効果:**
- freestyle-wifi.jpが「工事不要×無制限」として両方を同時訴求している影響で、ユーザーが「ポケットWiFi型も同じ?」と混乱する可能性への対応
- 賃貸ユーザーが「自宅固定用途ならホームルーター型のほうが安定」という判断を持てるようにして、SoftBank Air（実リンク済み・報酬¥18,000）への誘導を補強
- 申込踏み止め不安（「WiMAXのほうが良いのでは」）の直接解消
