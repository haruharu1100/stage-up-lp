## 3. 変更内容

### 3-1. ニッチ `one_person_room`（一人暮らし即日WiFi）

**対象案件**: SoftBank Air（報酬18,000円・実リンク設定済み）

#### pain_points 変更
**変更前（items 3・5が重複）:**
- item 3: SoftBank Air 8日キャンセル→費用ゼロで返品できるか・ZEUS WiFiのデータ上限を使い切った月に追加料金が発生するか
- item 5: SoftBank Air 届いて電波が弱い場合の8日キャンセルで返送料・手数料はいくらか・返品手順は

**変更後（items 3・5を1項目に統合、計7項目に整理）:**
- 統合item 3: 届いてコンセントに挿したが電波が弱い場合の8日以内キャンセルで **返送料・手数料・事務手数料3,300円の返金可否・返品手順** を1項目で解消
- item 4: 端末レンタルの場合の返却費用・傷汚れによる追加費用の有無を明確化

**期待効果**: 申込を踏み止める「8日キャンセルへの不安」を具体的金額で解消 → CTRとCVR向上

#### primary_appeal 変更
**変更前:**
```
【月2,618円〜・翌日発送・解約金なし｜費用重視→ZEUS WiFi・CB重視→SoftBank Airの2択で選ぶ一人暮らしWiFi2026】
```
**変更後:**
```
【月2,618円〜・翌日発送・解約金なし｜①費用重視→ZEUS WiFi ②CB重視→SoftBank Air ③ドコモユーザー→ドコモhome 5G（月4,290円〜・ドコモ公式にて確認）の3択で選ぶ一人暮らしWiFi2026】
```

**期待効果**: 競合が「3択比較」を標準化しているため、冒頭をキャリア別3択に対応。ドコモユーザー層の離脱を防止。

### 3-2. ニッチ `remote_worker`（テレワーク・Web会議落ちない回線）

**対象案件**: auひかり（25,000円）、BIGLOBE光（20,000円）、So-net光プラス（18,000円）、@nifty光（15,000円）

#### pain_points 変更
**追加した新pain_point:**
> 「光回線のキャッシュバック（申込から6〜12ヶ月後にメール案内）を受け取る前に転職・転勤・再引越しで解約が必要になった場合、CB受取権利は消滅するのか・引越し先で同プロバイダを継続利用すればCB権利を保持できるのか」

**期待効果**: テレワーカー（=転職・転勤リスクが高い層）が高額CBに躊躇する最大の不安を解消 → 申込後悔リスクを払拭してCV率向上。

#### search_keywords 変更
追加キーワード（2件）:
- `光回線 CB 受取前 転職 転勤 解約 失効 するか 引越し先 継続 保持 確認 2026`
- `テレワーク 光回線 失敗しない 後悔しない 選び方 確認 チェックリスト 2026`

#### primary_appeal 変更
**変更前:**
```
キャッシュバック特典（auひかり最大103,000円相当・So-net光プラス最大35,000円・@nifty光最大50,000円・BIGLOBE光最大40,000円・いずれも代理店経由・申込時要確認）
```
**変更後（ランキング形式）:**
```
キャッシュバック特典ランキング（2026年8月時点・代理店経由）：
①auひかり（最大103,000円相当目安・独自回線でZoom安定・auスマホセット割対応）
②@nifty光（最大50,000円＋他社違約金最大30,000円負担）
③BIGLOBE光（最大40,000円＋他社違約金最大40,000円負担）
④So-net光プラス（最大35,000円）
・CB受取前に転職・転勤で解約が必要になった場合は引越し先で同プロバイダを継続することでCB権利が保持される場合あり
```

**期待効果**: 競合（マイベスト等）のCBランキング形式に対抗。金額を一覧化し比較検討の離脱を防止。CB受取前解約リスクの解消で申込障壁を低減。

### 3-3. ニッチ `gamer`（ゲーマー向け低Ping回線）

**対象案件**: auひかり（25,000円）、So-net光プラス（18,000円）

#### pain_points 変更
**追加した新pain_point:**
> 「現在の光回線でNATタイプD（厳しい）になっていてオンラインゲームの接続が不安定な場合、auひかりの独自ルーターに変えるとNATタイプが改善（オープン/タイプB相当）する可能性はあるのか・auひかり申込後のポート開放設定の手順はサポートが教えてくれるのか」

**期待効果**: NATタイプDで悩むゲーマーは光回線乗換の最大の動機を持つ層。具体的な改善可能性の訴求でCV意欲を高める。

#### search_keywords 変更
追加キーワード（2件）:
- `NATタイプ D 光回線 乗換 auひかり 独自ルーター 改善 オープン タイプB なれるか 2026`
- `FPS ゲーム 光回線 乗換 Ping 改善 どのくらい 効果 体感 変わるか 実測 2026`

#### primary_appeal 変更
**変更前:**
```
ルーター乗換後のポート開放・NAT設定は新機器に合わせた再設定が必要（手順はプロバイダサポートへの電話・チャットで確認可能・NATタイプについても申込時確認推奨）
```
**変更後:**
```
ルーター乗換後のポート開放・NAT設定は新機器に合わせた再設定が必要（手順はプロバイダサポートへの電話・チャットで確認可能）・NATタイプD（厳しい）の状態でauひかり独自ルーターへ変更後にNATタイプが開放（オープン/タイプB相当）に改善したとのユーザー事例あり（回線環境・ルーター設定により結果は異なる・申込前にサポートへ確認推奨）
```

**期待効果**: NATタイプ改善への期待値を具体的に示し、長期のゲーム品質改善動機をCV行動に転換。
