# 2. 全動画に共通の原則

## 売るもの
AIではない。**「今やっている面倒な作業がどう変わるか」**。

- ×「最新AIを導入できます」「DXを支援します」
- ○「電話の内容が自動で文字になって残ります」「日報をLINEで送るだけで一覧表ができます」

## 構造
共通30〜40%＋業種別60〜70%。共通部分は使い回し、実演だけ差し替える。

## 尺
60〜90秒（最長120秒）。**最初の5秒**が全て。

## 字幕
**音を消しても全部わかること。** 会社では音を出さない人が多い。
- 1画面1メッセージ。2行まで。
- 文字サイズは大きく（スマホで読める）。
- 話者や機能名で色を変えない。地味に、読みやすく。

## 5秒の掴みの作り方
「〜していませんか？」の疑問形にする。断定すると「うちは違う」で終わる。疑問形なら相手が自分で当てはめる。

## 絶対にやらない
- MOCK・固定レスポンス・ダミー結果を「AIが実行した結果」として映す
- 実顧客の氏名・電話・住所・伝票番号・注文を映す
- 実績のない数字（「50%削減」「売上30%UP」）
- 「必ず」「絶対」「検索1位になります」
- 完成していない機能を完成品として映す

## 「できないこと」を必ず入れる
できることだけ並べた資料は疑われます。動画の最後かLPに必ず：
- AIが全部自動で判断するわけではありません
- 最終確認は人が行います
- お使いのシステムによっては連携できない場合があります

**これは弱点ではなく信用材料です。**

## DIGESTとの違いについて（理由を明示）
Vaultには「宣伝動画は静止画＋簡易描画では不可。アニメ風に動く高品質が必要」とあります。
これは**消費者向けガチャ宣伝**での検証結果です。今回のB2B営業動画は、**アニメより本物の画面録画のほうが説得力が高い**ため、後半は実画面を採用します。ただし前半の図解は「動く図解」にし、静止画の貼り合わせにはしません。

# 8. 動画URLの設計

```
https://（動画ページ）/v/{industry}?c={campaign_id}&co={company_id}
例: /v/kensetsu?c=2026q3-form&co=1995
```

**扱い方のルール**
- **個人の追跡ではなく、法人向けキャンペーンの効果測定として扱う**
- 記録するのは「どのキャンペーンの、どの業種の、どの会社宛URLが開かれたか」まで

- 使うサービスの利用規約・関連法令に従う

**注意**：前回「全社同じURL・視聴の記録は入れない」と決めていました。今回のご指示で**キャンペーン単位の計測を入れる方針に変更**します。個人単位ではなくキャンペーン単位である点が前回との違いです。

```
第7段  小さく1つだけ導入（30,000円）      ← ここが無いと決まらない
第8段  本契約
```

**第2段と第7段が生命線です。**
- 第2段：「打ち合わせ」は相手の1時間を奪うが、「1枚送る」は1分。返信率が変わる
- 第7段：いきなり大きい金額の判断を迫らない。1つだけ試せる段を必ず置く

CTAの言い方（軽い順）：
- 「1分の動画だけご覧ください」
- 「もし同じ作業があれば、今のやり方を1枚送ってください」
- 「御社向けの画面イメージを無料で1枚お作りします」

# 10. NG表現の一覧（全動画共通）

**景表法**
- 「必ず」「絶対」「確実に」
- 「50%削減」「売上30%UP」「利益が出ます」← 導入実績が無いため根拠なし
- 二重価格・カウントダウン・「今だけ」で急がせる
- サクラ・やらせのレビュー（ステマ規制）

**数字を出す場合**
実際にバックテスト等で確認した数字なら「**自社テストでは**」「**検証環境では**」と条件を明示する。母数が少ないときは断定しない。

**業種固有**
- SEO：「検索1位」「上位表示保証」→ 禁止
- EC：利益保証 → 禁止。他社価格の比較表 → 作らない
- 介護：AIが介護・医療の判断をする表現 → 禁止
- 電話：無差別架電を思わせる表現 → 禁止（同意取得が前提）
- 金融：無登録の投資助言 → 禁止
- 士業領域（補助金・契約書チェック）：「参考情報・目安」と明示。断定しない

**機能の言い方**
- 飲食のシフト・需要予測・「AIに聞く」→ 実際はAI非使用。「自動計算」と言う
- ガチャの「キャンペーン機能」→ 無い。「クーポン発行とバナー掲出」と言う
- ガチャの確率設定 → 「口数を入れると確率が決まる」方式

**撮影**
- MOCK・固定レスポンス・キー未設定の劣化出力を「AIの結果」として映さない
- MOCKを使うなら画面に「デモ画面」と明示する
- 本物として動いていない機能は**撮らない**

**個人情報**
実在の氏名・電話・メール・住所・顧客番号・注文・案件・顧客企業の秘密を映さない。撮影は必ず専用ダミーデータ。
