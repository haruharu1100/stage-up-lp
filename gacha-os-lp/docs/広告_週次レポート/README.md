## 1. CSVを6本ダウンロードする

Google広告にログイン済みのChromeで、以下6ページを順に開く。
各ページで **表の右上「ダウンロード」アイコン → メニューから `.csv`** を選ぶ。

| # | ページ | URL | 出来るファイル名 |
|---|---|---|---|
| 1 | 検索語句 | `https://ads.google.com/aw/keywords/searchterms?campaignId=24216002821&ocid=8361882474` | 検索語句レポート.csv |
| 2 | キーワード | `https://ads.google.com/aw/keywords?campaignId=24216002821&ocid=8361882474` | 検索キーワード レポート.csv |
| 3 | 除外キーワード | `https://ads.google.com/aw/keywords/negative?ocid=8361882474&campaignId=24216002821` | 除外キーワードのレポート.csv |
| 4 | 広告 | `https://ads.google.com/aw/ads?campaignId=24216002821&ocid=8361882474` | 広告レポート.csv |
| 5 | 変更履歴 | 左メニュー「変更履歴」から開く | 変更履歴レポート.csv |
| 6 | キャンペーン一覧 | `https://ads.google.com/aw/campaigns?ocid=8361882474` | キャンペーン レポート.csv |

### つまずきポイント（実際に起きた失敗）

- **ページ表示に18〜28秒かかる。** Googleのロゴが出ている間はクリックしても効かない。
- **ダウンロードのメニューは小さく出てから5〜10秒かけて広がる。** 広がりきる前に押すと1つ下の項目を選んでしまう。必ず待ってから、画面を見直して押す。
- **押した直後にページを移動するとダウンロードが取り消される。** 8〜10秒待ち、`~/Downloads` にファイルが出たのを確認してから次へ。
- **同じ押し方でも失敗することがある。** 失敗したらメニューを開き直して押し直す。毎回 `~/Downloads` を目視確認するのが確実。

## 3. レポート本文を書く

`2026-09-03_週次レポート.md` を雛形にして、同じ章立てで書く。

- 使い方（ChatGPTに投げる依頼文つき）
- §0 前提（何を売っているか／成功の定義＝相談件数／予算）
- §1 今週やったこと（変更履歴CSVから時刻つきで）
- §2 今の設定（キャンペーン設定／キーワードと状態／除外語／広告文）
- §3 安全装置
- §4 今の数字
- §5 **自分で分かっている弱点**（ここを正直に書かないとChatGPTが役に立たない）
- §6 来週やる予定・やらないと決めていること
- §7 添付CSV一覧
- §8 このレポートの信頼性について

### 書くときの絶対ルール

- **Googleの画面の要約文を信用しない。** 実際に、おすすめ欄が「サイトリンクがありません」と言っている一方で、広告レポートCSVは「サイトリンクをさらに2個追加してください」と言い、変更履歴にはサイトリンク4本の作成記録がある。**数字と事実はCSV（特に変更履歴）を正とする。**
- 推測で埋めない。分からないものは「不明」と書く。
- 景表法：「必ず」「絶対」「儲かる」は使わない。価格は通常価格のみ。
