# PHASE 1：オンラインオリパ標準導線との差分監査

作成日：2026-09-05
対象：AI GACHA OS（commit eac98aaa 時点）

## 参考にしたもの・していないもの

- 参考にしたのは **公開画面の情報設計（何がどこに置かれているか）だけ**です。
- 実際に公開サイト（oripa.ex-toreca.com）をブラウザで1回開き、**構造だけ**を数えました。
- **コード・HTML・CSS・画像・ロゴ・文章は、1つも取得していません。複製もしていません。**
- 配色・レイアウトの模倣もしません。AI GACHA OS 独自UIで作ります。

## A. 参考サイトの情報設計（自分の言葉で要約）

ブラウザで開いて、実際に画面上に存在することを確認できた構造：

## C. 「新規開業者が使える」までに足りないもの（Sだけ抜き出し）

1. **会員登録** — お客様が1人も増やせない
2. **ポイント購入** — 売上が1円も立たない
3. **残高不足のときの購入導線** — 買えないので行き止まり
4. **ガチャの商品画像** — 何が当たるか写真で見せられない
5. **会社情報・特商法・規約のページ** — 法律上、掲出しないと物を売れない

**この5つが揃うまで、新規開業者向けは NO-GO のままです。**

---

## D. いまの製品の強み（寄せる作業で壊してはいけないもの）

- **お金の計算が1円もずれない。** 残高と履歴の合計が常に一致することを実測済み
- **連打・2タブ・途中で再読み込み・戻る、どれでも二重に引かれない**
- **抽選結果は先にサーバーで確定し、演出はそれを再生するだけ。** 参考サイトに寄せる作業でここを崩すと、演出が結果を決める作りになり、公正性を失います
- **還元率が100%を超えると自動で止まる**
- **記録が改ざんできない鎖になっている**
- **会社ごとにデータが完全に分かれている**（他社のガチャ・他人の景品に手が届かないことを実測済み）

参考サイトに寄せるのは **見せ方と導線だけ**で、この土台は触りません。
