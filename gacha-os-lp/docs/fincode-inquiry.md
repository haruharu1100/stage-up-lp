### 0-1. ★先に決めておくこと：当社は「誰」なのか

照会の8割は、ここで決まります。**2つのうち、どちらかです。**

| | A案：**当社がまとめて契約する** | B案：**店舗ごとに契約してもらう** |
|---|---|---|
| 加盟店になるのは | 当社（1社） | 導入店舗（各社） |
| 売上が入るのは | 当社 → 店舗へ送金 | 店舗へ直接 |
| 当社の役割 | **決済の代理受領**（お金を預かる） | **仕組みの提供だけ**（お金に触らない） |
| 規約上の心配 | **「加盟店資格の第三者利用」に当たる可能性** | 小さい |
| 資金決済法 | **資金移動業に当たる可能性**（お金を預かるため） | 小さい |
| 店舗の手間 | 少ない（当社が代行） | **多い**（店舗ごとに審査） |
| 販売のしやすさ | 売りやすい | **審査待ちで導入が遅れる** |

**★現時点の当社の想定は「B案」です。**
理由は、A案は**規約と法律の両方で重い**からです。
「売りやすいから」でA案を選ぶと、**あとから止められたときに、預かったお金の行き先が問題になります**。

**ただし、B案でも当社が「プラットフォーム事業者」として
何らかの契約を結ぶ必要があるかは【未確定】です。それを聞くのが、この照会です。**

### ■ お金の流れ（ここが今回のご相談の中心です）

```
① お客様が「ポイント」を購入する（← ここで決済が発生します）
② お客様が、そのポイントを使ってくじを引く（← 決済は発生しません）
```

- **決済が発生するのは①のポイント購入時のみ**です。
- くじを引く操作（②）では、決済は発生しません。
- **①と③は切り離されており**、発送の遅延が与信の有効期限に影響しない設計としています。

## 3. 返事が来たら、何を記録するか

返事は**必ず文書に残してください**。口頭やチャットのままにしないこと。
「言った・聞いた」は、あとから確かめようがありません。

記録すること：

| 項目 | なぜ |
|---|---|
| 返事をくれた**会社名・部署・担当者名** | あとで別の担当者から違う話が出たときに、突き合わせるため |
| **日付** | 規約は変わります。いつ時点の回答かが無いと、来年には使えません |
| **10項目それぞれへの回答**（「個別審査による」も回答として記録） | 空欄にすると、聞いたかどうかが分からなくなります |
| **書面かどうか**（メール本文／PDF／口頭） | 口頭だけの回答は、審査の場で根拠になりません |

→ 記録先：`docs/payment-provider-research.md` の第2章（**【確定】の箱**）へ追記。
