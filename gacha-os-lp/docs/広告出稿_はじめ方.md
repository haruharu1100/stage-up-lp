## 1. なぜ Google 検索広告だけなのか

売る相手は「オンラインガチャ（オリパ）を運営している、またはこれから始める事業者」です。
日本に数百社しかいません。**とても狭い市場です。**

狭い市場では、媒体の選び方が逆になります。

- **広く配る広告（Instagram・Facebook・YouTube）は向きません。**
  「ガチャ事業者」という条件で人を選べないからです。
  99.9%は関係のない人に表示され、そのぶん課金されます。

- **検索広告は、相手のほうから名乗ってくれます。**
  「オリパ サイト 作り方」と自分で打ち込んだ人だけに出ます。
  月に数十回しか検索されない言葉でも、押した人は全員が見込み客です。

★1日1,000円という金額は「安く済ませたい」からではありません。
　**この市場は、それ以上出しても表示される回数が増えないからです。**
　狭い市場に予算を積むと、Googleは余った予算を使い切ろうとして、
　**関係のない検索にまで自分から広げます。** これが前回12万円が消えた仕組みです。

★1日1,000円で、実際にどれくらい起きるか（目安）

| | 30日での見込み |
|---|---|
| クリック単価 | 200〜400円（この分野は高めです） |
| クリック | 75〜150回 |
| デモを触った | 11〜22件 |
| 相談が入った | 1〜2件 |

　月3万円で相談が1件入り、そこから1社決まれば、
　月額49,800円なので**1か月以内に広告費を上回ります。**
　だから「相談1件」が損益の分かれ目です。0件なら止める、が下の「6」です。

## 1-2. 前回の広告で何が起きたか（ここが全部の根拠です）

アカウント『ガチャlp』で、2026-08-17 まで30日間出していた記録です。

| | 実績 |
|---|---|
| 型 | **P-MAX**（Googleが配信先を自動で広げる） |
| 1日あたり | 2,557円 |
| 表示回数 | 142,889回 |
| クリック | 2,148回 |
| 費用 | **121,937円** |
| 成果 | **0件** |

★この「0件」は「効かなかった」ではありません。
　**当時、成果を数える仕組みが入っていませんでした。**
　効いたのか効かなかったのかすら分からないまま終わった、が正確な状態です。
　はっきり失敗するより、これがいちばん高くつきます。

### 原因は2つだけです

**① P-MAX を使ったこと。**
8月12日に表示が38,288回に急増したのに、費用は3,355円しか増えていません。
**1回表示されて0.02円**という、極端に安い枠へ大量に流されただけです。
オンラインガチャ事業者は、その安い枠にはいません。

P-MAXは「客が大勢いる商品」を広く配る型です。
数百社しかいない市場では、Googleは行き場がなくて関係ない場所に配ります。
**だから今回は検索広告だけにします。P-MAXは使いません。**

**② 成果を返す線が無かったこと。**
これは今回すでに直してあります（下の「2」）。

### 前回から、そのまま使えるもの

- **Google広告タグ AW-18281740627**（作り直し不要）
- 検索キャンペーンの入れ物（日650円で作成済み・キーワード未投入のため0表示）

## 2. 出稿の前に、必ずやること（これが無いと全額ムダ）

広告は「何回押されたか」では良し悪しが分かりません。
100回押されて相談0件なら損、10回押されて相談1件なら大当たりです。

**「相談が入った」ことを広告側へ返す線**を先に引きます。
コード側の仕組みは今日つくりました（`config/ads.ts`）。
あとは Vercel の設定画面に、下の3つを貼るだけです。

```
NEXT_PUBLIC_GOOGLE_ADS_ID            AW-（Google広告で発行される番号）
NEXT_PUBLIC_GOOGLE_ADS_LABEL_CONTACT （相談完了のラベル）
NEXT_PUBLIC_GOOGLE_ADS_LABEL_DEMO    （デモ開始のラベル）
```

Google 広告の管理画面で「コンバージョン」を**2つ**作ってください。

| 名前 | いつ数えるか | 使い道 |
|---|---|---|
| 相談が入った | 相談フォームを送れたとき | **成果の判定** |
| デモを触った | デモ画面を開いたとき | **入札の目標** |

### ★ここを間違えると、広告は一生賢くなりません

Google の自動入札は、**月30件くらい成果が起きないと学習できません。**
相談は月に数件しか入りません。つまり相談だけを目標にすると、
広告は最後まで何も学習できないまま、単価だけが上がります。

- 入札の目標にするのは **「デモを触った」**（件数が多い）
- 成果として見るのは **「相談が入った」**（お金になる）

この2つを分けること。逆にしないこと。

## 3. 審査で落ちないために（この商品に固有の落とし穴）

Google 広告には「ギャンブルとゲーム」という審査区分があります。
日本では、ギャンブル関連の広告は**事前の認定が必要**で、
認定が下りるのは公営競技・宝くじなど限られたものだけです。

**AI GACHA OS はギャンブルではありません。**
事業者に売る業務システム（会計ソフトや在庫管理ソフトと同じ側）です。
ですが、審査は機械と人が短時間で見ます。
「ガチャ」「当たり」「引く」という言葉と、
実際にガチャを引ける画面が並んでいると、誤って止められることがあります。

### 守ること

1. **広告のリンク先を `/demo?side=customer`（お客様がガチャを引く画面）にしない。**
   ここが今いちばん危ないところです。実際にガチャが引けてしまうので、
   審査する側からは消費者向けのくじサイトに見えます。
   リンク先はトップページ（`/`）にしてください。

2. **広告文に「当たる」「高額」「一攫千金」を書かない。**
   売っているのは運営する側の道具です。買う人は引く人ではありません。

3. **広告文に必ず「事業者向け」「運営システム」を入れる。**
   審査する人が最初の3秒で「これは業務ソフトだ」と分かる形にします。

4. 万一止められたら、異議申し立てで
   **「消費者向けサービスではなく、事業者向けの業務管理システムである」**
   と書いて出し直します。1回で通らなくても普通のことです。

## 4-2. 設定の3か所（前回12万円が消えたのは、ここです）

★キーワードや広告文より、**この3つのほうが結果を決めます。**
　既定のままにすると、Googleは予算を使い切るために配信先を勝手に広げます。

### ① 入札は「個別クリック単価（手動）」・上限400円

前回の設定は「クリック数の最大化」でした。
これは **1円でも多くクリックを取りにいく**設定です。
すると Google は**いちばん安いクリック**を集めます。
安いクリックとは、誰も欲しがっていない枠のクリックです。
日1,000円だと、この設定は最悪の相性になります。

- 入札戦略：**個別クリック単価（手動）**
- 上限クリック単価：**400円**
- ★自動入札に切り替えていいのは、**デモの成果が月30件を超えてから**です。
　　それ以前は、広告に学習させる材料がありません。

### ② 地域は「日本」＋「所在地」に限定

Google広告の既定は「所在地**または**関心のある場所」です。
このままだと「日本に関心がある海外の人」にも出ます。
オリパ事業者は日本にしかいません。

- 地域：日本
- 地域設定のオプション：**「ターゲット地域に所在するユーザー」に変更する**
- ★ここは既定のままだと必ず海外へ漏れます。前回もこの設定でした。

### ③ キーワードは「完全一致」と「フレーズ一致」だけ

部分一致（何も記号を付けない書き方）は、
Google が「意味が近い」と判断した言葉にも出します。
「オリパ システム」から「ガチャ ゲーム 無料」まで広がります。

- `[オリパ システム]` … 完全一致（この言葉だけ）
- `"オリパ システム"` … フレーズ一致（この並びを含むもの）
- **記号なしの書き方は使わない**

### そのほか、最初に必ず切るもの

| 項目 | どうするか | 理由 |
|---|---|---|
| ディスプレイネットワーク | **オフ** | 検索キャンペーンの既定でオンになっています。アプリ内広告に配信され、誤タップで消えます |
| 検索パートナー | **オフ** | Google以外の検索窓に出ます。最初は判定材料を汚さない |
| 自動作成アセット | **オフ** | Googleが広告文を勝手に作ります。「当たる」等が入ると審査で落ちます |
| 広告のローテーション | 均等配信 | 3本の広告文を公平に比べるため |

| 見る数字 | 良い | 危ない | 危ないときの手当て |
|---|---|---|---|
| 表示回数 | 週150回以上 | 週30回未満 | キーワードが狭すぎる。A群を足す |
| クリック率 | 3%以上 | 1%未満 | 広告文が刺さっていない。見出しを差し替える |
| クリック単価 | 400円未満 | 上限に張り付く | 完全一致だけに絞る |
| デモを触った率 | クリックの15%以上 | 5%未満 | LPの上のほうが伝わっていない |

★毎週かならず「検索語句」の一覧を開いてください。
　**実際にどんな言葉で押されたか**が出ます。関係ない言葉は、その場で除外に入れます。
　前回はこれを見ていませんでした。ここを毎週やるだけで、ムダの大半が止まります。

### 止める基準（決めておかないと、だらだら払い続けます）

**30日たって「相談0件 かつ デモ5件未満」なら、いったん停止します。**
そのときに直すのは広告ではなく、**LPの上半分**です。
デモまで届いていないなら、広告文とLPの言っていることがずれています。

逆に「デモは触られているのに相談0件」なら、広告は当たっています。
直すのは**相談フォームの手前**（料金の見せ方・不安の消し方）です。
