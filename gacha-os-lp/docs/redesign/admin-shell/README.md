# 左メニューが、どの画面でも最後まで届くこと

## 直す前に、実際に測った値

| 画面の大きさ | メニュー下端 | 画面の高さ | 届くか |
| --- | --- | --- | --- |
| 1440×900 | 978px | 900px | ✗ 78px はみ出し |
| 1366×768 | 846px | 768px | ✗ 78px はみ出し |
| 1280×720 | 798px | 720px | ✗ 78px はみ出し |
| 1024×768 | 873px | 768px | ✗ 105px はみ出し |

はみ出した場所に「ログアウト」と「販売サイトへ戻る」が入っていました。
中でいくらスクロールしても、画面の外なので届きません。

原因は、上のバーの高さを 6.5rem（104px）と見積もって
引き算していたことです。実物は 128px、
1024px 幅では注意書きが2行になって 156px でした。

## 直したあと

高さの引き算をやめ、入れ子の箱に高さを配らせています。
いちばん下の操作は、スクロールする一覧の外に留めました。

| 画面の大きさ | 操作 | 下端 | 画面 | 届くか |
| --- | --- | --- | --- | --- |
| 1440x900 | デモを最初に戻す | 775px | 900px | ✓ |
| 1440x900 | ログアウト | 834px | 900px | ✓ |
| 1440x900 | 販売サイトへ戻る | 888px | 900px | ✓ |
| 1366x768 | デモを最初に戻す | 643px | 768px | ✓ |
| 1366x768 | ログアウト | 702px | 768px | ✓ |
| 1366x768 | 販売サイトへ戻る | 756px | 768px | ✓ |
| 1280x720 | デモを最初に戻す | 595px | 720px | ✓ |
| 1280x720 | ログアウト | 654px | 720px | ✓ |
| 1280x720 | 販売サイトへ戻る | 708px | 720px | ✓ |
| 1024x768 | デモを最初に戻す | 643px | 768px | ✓ |
| 1024x768 | ログアウト | 702px | 768px | ✓ |
| 1024x768 | 販売サイトへ戻る | 756px | 768px | ✓ |
