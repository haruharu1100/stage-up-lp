# 使いやすさの確認（はみ出していないか、ではなく）

`node scripts/check-admin-ux.mjs http://localhost:3210` が撮った写真です。
写真だけでなく、押した回数まで機械が数えています。

## ① 目的の画面まで、何回押して着いたか

ダッシュボードが出ている状態から数えています。
PCでは左メニューは最初から出ているので、「メニューを開く」は数に入れません。

| やりたいこと | 押した回数 | 上限 | 着いた先 |
| --- | --- | --- | --- |
| 発送を見る | 1回 | 2回 | 発送管理 |
| 危険なガチャを見る | 1回 | 2回 | 実還元率 |
| AIガチャ作成をはじめる | 1回 | 1回 | AI ガチャ作成 |
| 問い合わせを確認する | 1回 | 2回 | 問い合わせ |

毎日何十回も通る道です。1回増えると、1年で数千回増えます。

## ② 一覧の行を押すと、右の板が開くか

表は情報を削って一覧性を出す仕組みです。
削った先が無ければ、ただ情報が消えただけになります。

| 画面 | 行を押す | Esc で閉じる | 写真 |
| --- | --- | --- | --- |
| ガチャ管理 | ✓ | ✓ | `drawer-gacha.png` |
| 発送管理 | ✓ | ✓ | `drawer-shipping.png` |
| 問い合わせ | ✓ | ✓ | `drawer-support.png` |
| 会員管理 | ✓ | ✓ | `drawer-customers.png` |

★操作ボタンは表の中に並べていません。
行そのものが「開く」ボタンなので、そこに「公開する」を並べると、
行を開くつもりで公開してしまう事故が起きます。
操作は、板の中に入ってから押します。

## ③ キーボードだけで操作できるか

| キー | すること | 結果 |
| --- | --- | --- |
| Tab → Enter | 行を開く | ✓ 板が開いた |
| Esc | 板を閉じる | ✓ 閉じた |
| ⌘K | 画面を探す | ✓ 「発送」で先頭に「発送管理」（`cmdk.png`） |

毎日使う方は、必ずマウスから手を離します。

## ④ お知らせ帯が、次の画面まで居座らないか

画面の上に出ている文は、いま見ている画面の話だと読まれます。
ガチャの結果が発送の画面の上に残っていれば、発送で何かが起きたのだと
読み違えます。実物の画面で、次の3つを確かめています。

| 確かめたこと | 結果 |
| --- | --- |
| ログインした直後、帯が出る | ✓「運営 太郎（管理者（全権））としてログインしました。」 |
| 画面を移ったら、帯が消える | ✓ 発送管理へ移った時点で消えた |
| 何もしなくても、時間で消える | ✓ 6000ミリ秒で自分から消えた |
| 読み終えられる長さか | ✓ 6000ミリ秒（4000ミリ秒未満は落とす） |

★ログイン直後の帯だけは、すぐに消してはいけません。
最初の画面が出ることを「移動」と数えると、ログインの知らせが一瞬で消えます。
そこも含めて機械が見ています。

## 撮り直し方

```
npm run dev
npm run check:ux -- http://localhost:3210
npm run check:flash -- http://localhost:3210
```

1つでも守れていなければ、終了コード 1 で落ちます。
写真を撮るだけで終わらせないための道具です。

★`npm run build` を走らせたあとは、開発サーバーを立て直してください。
両方が同じ置き場（`.next`）を使うので、片方が片方の中身を上書きします。
上書きされたままだと、画面がボタンに反応しなくなり、
「直っていないのに落ちている」ように見えます。
